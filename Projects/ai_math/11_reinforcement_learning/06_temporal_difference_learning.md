# Module 11.6: Temporal-Difference Learning (TD(0))

---

## 1. Intuition & 101 Motivation

In the previous chapter on Monte Carlo (MC) methods, an agent had to wait until an entire episode terminated before calculating the cumulative return $G_t$ and updating its state-value estimate $V(S_t)$. While MC requires no model of transition probabilities $\mathcal{P}$, it suffers from two major limitations:
1. **High Variance:** Return $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$ aggregates stochastic rewards and state transitions across an entire horizon, compounding stochastic noise.
2. **Episodic Restriction:** MC cannot learn in non-terminating (continuing) tasks or during long episodes; it must wait until the episode ends.

**Temporal-Difference (TD) learning** combines the core advantages of Dynamic Programming (DP) and Monte Carlo (MC):
- Like MC, TD learns directly from raw experience **without requiring an environment transition model** $\mathcal{P}_{ss'}^a$ or reward function $\mathcal{R}_s^a$.
- Like DP, TD **bootstraps**: it updates its value estimate based on other learned estimates, immediately after a single time step ($1$-step lookahead), without waiting for the terminal state.

```
       Dynamic Programming (DP)                  Monte Carlo (MC)
       [Full Tree Model, 1-Step]             [Sample Trajectory, Full Episode]
                 (s)                                       (s)
               /  |  \                                      |
             (a) (a) (a)                                   (a)
             / \  |  / \                                    |
           (s')(s')(s')(s')                                (s')
                                                            |
                                                           ...
                                                            |
                                                       (Terminal)

                          Temporal-Difference TD(0)
                        [Sample Trajectory, 1-Step]
                                    (s)
                                     |
                                    (a)
                                     |
                                    (s')  <-- Bootstraps off V(s')!
```

## 2. Rigorous Mathematical Formulation

### 2.1 The One-Step TD Update and The TD Error

Let $S_t$ be the state visited at discrete time $t$. The agent takes action $A_t \sim \pi(\cdot \mid S_t)$, receives numerical reward $R_{t+1}$, and transitions to successor state $S_{t+1} \sim \mathcal{P}(\cdot \mid S_t, A_t)$.

The **target** in TD(0) is the one-step truncated return:
$$G_{t:t+1} \triangleq R_{t+1} + \gamma V(S_{t+1})$$

The **Temporal-Difference Error (TD error)** $\delta_t$ is defined as the difference between this 1-step bootstrapped target and the current estimate:
$$\delta_t \triangleq R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$$

The tabular TD(0) state-value update rule is:
$$V(S_t) \leftarrow V(S_t) + \alpha \delta_t = V(S_t) + \alpha \left[ R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \right]$$
where $\alpha \in (0, 1]$ is the scalar learning rate.

---

### 2.2 Mathematical Expectation & Bellman Operator Relation

Recall the Bellman expectation equation for policy $\pi$:
$$V^\pi(s) = \mathbb{E}_\pi \left[ R_{t+1} + \gamma V^\pi(S_{t+1}) \mid S_t = s \right] = (\mathcal{T}^\pi V^\pi)(s)$$

If the value function estimate $V$ is equal to the true fixed point $V^\pi$, the expected TD error given state $S_t = s$ vanishes:
$$\mathbb{E}_\pi \left[ \delta_t \mid S_t = s \right] = \mathbb{E}_\pi \left[ R_{t+1} + \gamma V^\pi(S_{t+1}) - V^\pi(S_t) \mid S_t = s \right] = (\mathcal{T}^\pi V^\pi)(s) - V^\pi(s) = 0$$

Thus, $\delta_t$ is an unbiased sample estimate of the **Bellman residual** $(\mathcal{T}^\pi V)(s) - V(s)$.

---

### 2.3 Stochastic Approximation & Robbins-Monro Convergence

#### Theorem: Almost Sure Convergence of Tabular TD(0) (Dayan, 1992; Tsitsiklis & Van Roy, 1997)
Let the MDP have finite state space $\mathcal{S}$ and finite reward variance $\sigma_R^2 < \infty$. Suppose the Markov chain induced by stationary policy $\pi$ is irreducible and aperiodic with stationary distribution $d^\pi(s) > 0$ for all $s \in \mathcal{S}$.
If the step-size schedule $\alpha_t(s)$ satisfies the **Robbins-Monro conditions**:
$$\sum_{t=1}^\infty \alpha_t(s) = \infty \quad \text{and} \quad \sum_{t=1}^\infty \alpha_t^2(s) < \infty \quad \forall s \in \mathcal{S}$$
then as $t \to \infty$, the sequence of value estimates $V_t(s)$ generated by TD(0) converges **almost surely** to the true unique fixed point $V^\pi(s)$:
$$\mathbb{P} \left( \lim_{t \to \infty} V_t(s) = V^\pi(s) \right) = 1 \quad \forall s \in \mathcal{S}$$

#### Proof Sketch (Contraction & Martingale Difference)
1. Rewrite the TD update in vector form:
   $$\mathbf{V}_{t+1} = \mathbf{V}_t + \alpha_t \mathbf{D}_t \left( \mathbf{R}_{t+1} + \gamma \mathbf{P}_{t+1} \mathbf{V}_t - \mathbf{V}_t \right)$$
   where $\mathbf{D}_t = \operatorname{diag}(\mathbb{I}(S_t = s))$.
2. Taking conditional expectation with respect to the filtration $\mathcal{F}_t$:
   $$\mathbb{E} [\mathbf{V}_{t+1} \mid \mathcal{F}_t] = \mathbf{V}_t + \alpha_t \mathbf{D} \left( \mathcal{T}^\pi \mathbf{V}_t - \mathbf{V}_t \right)$$
   where $\mathbf{D} = \operatorname{diag}(d^\pi(s))$ is positive definite.
3. Because $\mathcal{T}^\pi$ is a $\gamma$-contraction in the $L_2(d^\pi)$ norm (as proven in Chapter 11.4), the ODE method for stochastic approximation (Borkar & Meyn) guarantees that the discrete stochastic process tracks the stable linear differential equation:
   $$\dot{\mathbf{V}}(\tau) = \mathbf{D} \left( \mathcal{T}^\pi \mathbf{V}(\tau) - \mathbf{V}(\tau) \right)$$
   Since the eigenvalues of $\mathbf{D}(\gamma \mathbf{P}^\pi - \mathbf{I})$ have strictly negative real parts, the unique global attractor is $\mathbf{V}^* = V^\pi$. $\blacksquare$

---

### 2.4 Batch TD(0) vs. Batch Monte Carlo: The Certainty-Equivalence Distinction

When presenting a finite batch of $M$ repeated episodes to both TD(0) and Monte Carlo repeatedly until convergence:
1. **Batch Monte Carlo** converges to the estimate that minimizes the empirical mean squared error with respect to actual trajectory returns:
   $$V_{\text{MC}} = \arg \min_V \sum_{m=1}^M \sum_{t=0}^{T_m} \left( G_t^{(m)} - V(S_t^{(m)}) \right)^2$$
2. **Batch TD(0)** converges to the **certainty-equivalence estimate**: it first implicitly forms the maximum-likelihood estimate of the underlying Markov process model $(\hat{\mathcal{P}}, \hat{\mathcal{R}})$, and then solves the exact Bellman equation for that model:
   $$V_{\text{TD}} = \left( \mathbf{I} - \gamma \hat{\mathbf{P}}^\pi \right)^{-1} \hat{\mathbf{R}}^\pi$$

This distinction explains why TD(0) consistently outperforms Monte Carlo on Markovian environments: TD leverages the Markov property (exploiting transition graph structure), whereas MC treats each state visit independently of the chain's graph topology.

## 3. Geometric & Physical Interpretation

### 3.1 Projection in State-Value Function Space

In the $|\mathcal{S}|$-dimensional Euclidean space of value functions $\mathbb{R}^{|\mathcal{S}|}$:
- The true value function $\mathbf{V}^\pi$ is the intersection point where $\mathcal{T}^\pi \mathbf{V} = \mathbf{V}$.
- An empirical Monte Carlo update moves directly towards the sample return vector $\mathbf{G}$, which has zero bias ($\mathbb{E}[\mathbf{G}] = \mathbf{V}^\pi$) but large variance sphere around $\mathbf{V}^\pi$.
- A TD(0) step moves towards the 1-step Bellman projection target $\mathbf{R} + \gamma \mathbf{P} \mathbf{V}_t$. The error vector $\delta_t$ pulls the estimate toward the dynamic surface defined by the current estimate, geometrically dampening variance at the expense of an initial contractual bias.

```
                  V-Space (R^|S|)
                       ^
                       |              Sample Return G_t (High Variance)
                       |             *
                       |            /
                       |           /
                       |          * True V*
                       |         /
                       |        /
                       |       * TD Target: R_{t+1} + gamma V(S_{t+1}) (Low Variance)
                       |      /
                       |     /
                       |    * Current Estimate V_t
                       +----------------------------------->
```

## 4. Real-World Analogy: Commute Time Prediction

Imagine you are driving home from work. You want to estimate your total commute time:
- **Monte Carlo Approach:** You leave your office at 5:00 PM. You get stuck in sudden highway traffic, then hit construction, and finally arrive home at 5:50 PM (50 minutes). You record a single data point: "Leaving office = 50 min". You cannot update your estimate when you see the traffic jam at 5:15 PM; you must wait until you park in your driveway.
- **Temporal-Difference Approach:** 
  - At 5:00 PM (Office), you estimate 30 min total.
  - At 5:15 PM (Highway entrance), you see severe bumper-to-bumper congestion. You now estimate it will take 40 more minutes from here (total 15 + 40 = 55 min).
  - Immediately, right at the highway entrance, your TD error is:
    $$\delta = (\text{Time elapsed: } 15\text{ min}) + (\text{New remaining estimate: } 40\text{ min}) - (\text{Initial estimate: } 30\text{ min}) = +25\text{ min}$$
  - You immediately update your estimate for "Leaving office" from 30 min towards 55 min without waiting to reach home!

## 5. Prof. Tom Yeh "AI by Hand" Visual Grids

### 5.1 Problem Setup: 3-State Chain
We consider a deterministic 3-state chain MDP:
$$S_1 \xrightarrow{a} S_2 \xrightarrow{a} S_3 \xrightarrow{a} \text{Terminal}$$
- Discount factor: $\gamma = 0.9000$
- Learning rate: $\alpha = 0.5000$
- Initial value estimates: $V_0(S_1) = 0.0000, \quad V_0(S_2) = 0.0000, \quad V_0(S_3) = 0.0000$
- Transition rewards:
  - Transition $S_1 \to S_2$: $R_1 = 0.0000$
  - Transition $S_2 \to S_3$: $R_2 = 0.0000$
  - Transition $S_3 \to \text{Terminal}$: $R_3 = 10.0000$

We will execute **Episode 1** step-by-step by hand, computing the TD error $\delta_t$ and updating each state.

### 5.2 "What Refers to What" Legend Protocol

| Symbol | Mathematical Entity | Concrete Value / Meaning in Hand Walkthrough |
| :--- | :--- | :--- |
| $S_t$ | Current State | State visited at step $t \in \{S_1, S_2, S_3\}$ |
| $S_{t+1}$ | Successor State | Next state transitioned into ($S_2, S_3, \text{Terminal}$) |

### 5.3 Step-by-Step Hand Calculations (Episode 1)

#### Step 1: Transition $S_1 \to S_2$ with Reward $R_1 = 0.0$
- Current estimates: $V(S_1) = 0.0, V(S_2) = 0.0$
- TD Target:
  $$\text{Target}_0 = R_1 + \gamma V(S_2) = 0.0 + 0.9 \times 0.0 = \mathbf{0.0000}$$
- TD Error:
  $$\delta_0 = \text{Target}_0 - V(S_1) = 0.0000 - 0.0000 = \mathbf{0.0000}$$
- Value Update for $S_1$:
  $$V_1(S_1) = V_0(S_1) + \alpha \delta_0 = 0.0000 + 0.5 \times 0.0000 = \mathbf{0.0000}$$

#### Step 2: Transition $S_2 \to S_3$ with Reward $R_2 = 0.0$
- Current estimates: $V(S_2) = 0.0, V(S_3) = 0.0$
- TD Target:
  $$\text{Target}_1 = R_2 + \gamma V(S_3) = 0.0 + 0.9 \times 0.0 = \mathbf{0.0000}$$
- TD Error:
  $$\delta_1 = \text{Target}_1 - V(S_2) = 0.0000 - 0.0000 = \mathbf{0.0000}$$
- Value Update for $S_2$:
  $$V_1(S_2) = V_0(S_2) + \alpha \delta_1 = 0.0000 + 0.5 \times 0.0000 = \mathbf{0.0000}$$

#### Step 3: Transition $S_3 \to \text{Terminal}$ with Reward $R_3 = 10.0$
- Terminal state value is identically zero: $V(\text{Terminal}) = 0.0$
- TD Target:
  $$\text{Target}_2 = R_3 + \gamma V(\text{Terminal}) = 10.0 + 0.9 \times 0.0 = \mathbf{10.0000}$$
- TD Error:
  $$\delta_2 = \text{Target}_2 - V(S_3) = 10.0000 - 0.0000 = \mathbf{10.0000}$$
- Value Update for $S_3$:
  $$V_1(S_3) = V_0(S_3) + \alpha \delta_2 = 0.0000 + 0.5 \times 10.0000 = \mathbf{5.0000}$$

State-values at the end of Episode 1:
$$\mathbf{V}_1 = [V(S_1)=0.0000, \quad V(S_2)=0.0000, \quad V(S_3)=\mathbf{5.0000}]$$

### 5.4 Step-by-Step Hand Calculations (Episode 2)

Now let's trace the second episode through the exact same path to observe **information propagating backward**!

#### Step 1: Transition $S_1 \to S_2$ with Reward $R_1 = 0.0$
- Current estimates: $V(S_1) = 0.0, V(S_2) = 0.0$
- $\text{Target}_0 = 0.0 + 0.9 \times 0.0 = 0.0000 \implies \delta_0 = 0.0 \implies V_2(S_1) = \mathbf{0.0000}$

#### Step 2: Transition $S_2 \to S_3$ with Reward $R_2 = 0.0$
- Current estimates: $V(S_2) = 0.0$, but now $V(S_3) = \mathbf{5.0000}$!
- TD Target:
  $$\text{Target}_1 = R_2 + \gamma V(S_3) = 0.0 + 0.9 \times 5.0000 = \mathbf{4.5000}$$
- TD Error:
  $$\delta_1 = \text{Target}_1 - V(S_2) = 4.5000 - 0.0000 = \mathbf{4.5000}$$
- Value Update for $S_2$:
  $$V_2(S_2) = V_1(S_2) + \alpha \delta_1 = 0.0000 + 0.5 \times 4.5000 = \mathbf{2.2500}$$

#### Step 3: Transition $S_3 \to \text{Terminal}$ with Reward $R_3 = 10.0$
- Current estimate: $V(S_3) = 5.0000$
- TD Target: $10.0 + 0.0 = 10.0000$
- TD Error: $\delta_2 = 10.0000 - 5.0000 = \mathbf{5.0000}$
- Value Update for $S_3$:
  $$V_2(S_3) = 5.0000 + 0.5 \times 5.0000 = \mathbf{7.5000}$$

State-values at the end of Episode 2:
$$\mathbf{V}_2 = [V(S_1)=0.0000, \quad V(S_2)=\mathbf{2.2500}, \quad V(S_3)=\mathbf{7.5000}]$$

## 6. Solved Illustrations

### Illustration 1: The Classic "AB Example" (Sutton Example 6.4)
**Problem:**
Suppose an agent observes 8 episodes in an unknown MDP with two non-terminal states $A$ and $B$. All episodes terminate immediately after the recorded steps:
- Episode 1: $A \to 0, B \to 0$
- Episode 2: $B \to 1$
- Episode 3: $B \to 1$
- Episode 4: $B \to 1$
- Episode 5: $B \to 1$
- Episode 6: $B \to 1$
- Episode 7: $B \to 1$
- Episode 8: $B \to 0$
Assume $\gamma = 1.0$. What are the values $V(A)$ and $V(B)$ under:
1. Batch Monte Carlo?
2. Batch TD(0)?

**Solution:**
- **Evaluating State $B$:**
  In all 8 episodes, $B$ appears 8 times: 6 times it yielded reward $1$, and 2 times it yielded reward $0$.
  Both Batch MC and Batch TD agree on $B$:
  $$V(B) = \frac{6 \times 1 + 2 \times 0}{8} = \frac{6}{8} = \mathbf{0.75}$$

- **Evaluating State $A$:**
  - **Batch Monte Carlo:** State $A$ was visited only once (Episode 1), and its subsequent return was $0$. Batch MC minimizes squared error to observed sample returns:
    $$V_{\text{MC}}(A) = \mathbf{0.00}$$
  - **Batch TD(0):** TD(0) builds the maximum likelihood Markov transition model. State $A$ transitioned $100\%$ of the time to $B$ with reward $0$.
    According to the Markov property:
    $$V_{\text{TD}}(A) = R + \gamma V(B) = 0 + 1.0 \times 0.75 = \mathbf{0.75}$$

**Conclusion:** 
TD(0) correctly recognizes that entering $A$ guarantees transition to $B$, which has an expected payout of $0.75$. Batch MC overfits to the single observed sample return, ignoring the transition graph structure. $\blacksquare$

## 7. Deep Learning Connection & Application

### 1. Critic Baselines in Actor-Critic (A2C & PPO)
In modern deep actor-critic methods, the critic neural network $V_\phi(s)$ is trained using the TD error loss:
$$\mathcal{L}_{\text{critic}}(\phi) = \frac{1}{|B|} \sum_{i \in B} \left( R_{t+1}^{(i)} + \gamma V_{\phi_{\text{targ}}}(S_{t+1}^{(i)}) - V_\phi(S_t^{(i)}) \right)^2$$
The resulting TD error $\delta_t$ acts as the empirical **advantage estimate** $\hat{A}_t = \delta_t$, guiding the policy gradient update:
$$\nabla_\theta J(\theta) \approx \sum_t \nabla_\theta \log \pi_\theta(A_t \mid S_t) \delta_t$$

### 2. Deep Q-Networks (DQN)
DQN is the deep neural network extension of 1-step TD learning applied to action-values:
$$\mathcal{L}(\theta) = \mathbb{E} \left[ \left( R + \gamma \max_{a'} Q(S', a'; \theta^-) - Q(S, A; \theta) \right)^2 \right]$$
where the target uses a periodic "frozen" target network $\theta^-$ to stabilize the bootstrapped TD target.
