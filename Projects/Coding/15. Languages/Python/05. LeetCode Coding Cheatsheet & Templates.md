## 2. Priority Queue (`heapq`) Idioms

Python's `heapq` is strictly a **min-heap**.

### 2.1 Basic Operations
```python
import heapq

heap = []
heapq.heappush(heap, 10)
heapq.heappush(heap, 5)
heapq.heappush(heap, 15)

smallest = heapq.heappop(heap)  # 5

# O(N) In-place array heapification:
nums = [9, 3, 2, 8, 1]
heapq.heapify(nums)             # nums is now a valid min-heap
```

### 2.2 Max-Heap Pattern
To store elements in a max-heap, invert the sign upon pushing and popping:
```python
max_heap = []
heapq.heappush(max_heap, -val)
largest = -heapq.heappop(max_heap)
```

### 2.3 Priority Queue with Custom Objects (Tuple Wrapper)
Tuples are compared element-by-element from left to right. When priorities are equal, Python compares subsequent tuple elements:
```python
import itertools

pq = []
counter = itertools.count()  # Unique tie-breaker sequence counter

# (priority, tie_breaker, payload)
heapq.heappush(pq, (dist, next(counter), node))

dist, _, node = heapq.heappop(pq)
```

## 3. Binary Search Templates (`bisect` & Manual)

### 3.1 Using Python's `bisect` Module
```python

# bisect_right: First index where arr[i] > target (upper_bound)

```

### 3.2 Standard Manual Binary Search (Inclusive Bounds)
```python
def binary_search(nums: list[int], target: int) -> int:
    left, right = 0, len(nums) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
            
    return -1
```

### 3.3 Binary Search on Monotonic Predicate / Optimization (Search Space)
```python
def binary_search_predicate(low: int, high: int) -> int:
    """Finds the minimum value x in [low, high] satisfying condition(x) == True."""
    ans = high
    while low <= high:
        mid = low + (high - low) // 2
        if condition(mid):
            ans = mid
            high = mid - 1  # Try searching for a smaller valid value
        else:
            low = mid + 1   # Need a larger value
    return ans
```

## 4. Union-Find (Disjoint Set Union - DSU) Template

Features **Path Compression** and **Union by Rank/Size** ($\mathcal{O}(\alpha(N))$ nearly $\mathcal{O}(1)$ time per operation).

```python
class UnionFind:
    def __init__(self, size: int):
        self.parent = list(range(size))
        self.rank = [1] * size
        self.num_components = size

    def find(self, x: int) -> int:
        # Path compression: points node directly to root
        root = x
        while root != self.parent[root]:
            root = self.parent[root]
        
        curr = x
        while curr != root:
            nxt = self.parent[curr]
            self.parent[curr] = root
            curr = nxt
            
        return root

    def union(self, x: int, y: int) -> bool:
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x == root_y:
            return False  # Already connected (cycle detected)
        
        # Union by rank
        if self.rank[root_x] < self.rank[root_y]:
            root_x, root_y = root_y, root_x
        
        self.parent[root_y] = root_x
        if self.rank[root_x] == self.rank[root_y]:
            self.rank[root_x] += 1
            
        self.num_components -= 1
        return True

    def connected(self, x: int, y: int) -> bool:
        return self.find(x) == self.find(y)
```

## 5. Trie (Prefix Tree) Template

```python
class TrieNode:
    def __init__(self):
        self.children: dict[str, TrieNode] = {}
        self.is_end_of_word: bool = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        curr = self.root
        for char in word:
            if char not in curr.children:
                curr.children[char] = TrieNode()
            curr = curr.children[char]
        curr.is_end_of_word = True

    def search(self, word: str) -> bool:
        curr = self.root
        for char in word:
            if char not in curr.children:
                return False
            curr = curr.children[char]
        return curr.is_end_of_word

    def starts_with(self, prefix: str) -> bool:
        curr = self.root
        for char in prefix:
            if char not in curr.children:
                return False
            curr = curr.children[char]
        return True
```

## 6. Monotonic Stack Template (Next Greater Element)

```python
def next_greater_elements(nums: list[int]) -> list[int]:
    """Returns an array where res[i] is the next greater element to the right of nums[i]."""
    n = len(nums)
    res = [-1] * n
    stack = []  # Stores indices of a monotonic strictly decreasing sequence

    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:
            idx = stack.pop()
            res[idx] = nums[i]
        stack.append(i)

    return res
```

## 7. Sliding Window Maximum Template (`collections.deque`)

```python
from collections import deque

def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq = deque()  # Stores indices; monotonic decreasing order of values
    res = []

    for i, num in enumerate(nums):
        # 1. Evict elements outside the current window [i - k + 1, i]
        while dq and dq[0] < i - k + 1:
            dq.popleft()

        # 2. Maintain decreasing order: remove smaller elements from back
        while dq and nums[dq[-1]] <= num:
            dq.pop()

        dq.append(i)

        # 3. Append max for window once window size reaches k
        if i >= k - 1:
            res.append(nums[dq[0]])

    return res
```
