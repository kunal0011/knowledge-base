## 2. `list`: The Dynamic Array

In CPython, a `list` is **not** a linked list. It is an array of pointers (`PyObject**`) to other objects in memory.

### 2.1 Over-allocation & Growth Factor
When a list grows beyond its current capacity, CPython allocates a new contiguous block with extra padding to guarantee **amortized $\mathcal{O}(1)$** appends.

The growth formula in CPython:
$$\text{new\_allocated} = \text{newsize} + (\text{newsize} \gg 3) + (\text{newsize} < 9 \text{ ? } 3 : 6)$$

```
Length   Capacity
0        0
1        4
5        8
9        16
17       25
26       35
47       58
```
Growth factor is approximately $\approx 1.125\times$, which is more conservative than C++'s `std::vector` ($2.0\times$ or $1.5\times$), prioritizing memory conservation.

### 2.2 Performance Critical Nuance: `pop(0)` vs `pop()`
- `list.pop()` removes the last pointer and decrements `ob_size`: **$\mathcal{O}(1)$ time**.
- `list.pop(0)` shifts all remaining $N-1$ pointers one slot to the left using C's `memmove`: **$\mathcal{O}(N)$ time**.
- **Interview Rule:** Never implement a queue using `list` with `pop(0)`. Always use `collections.deque`.

## 3. `dict`: The Compact Hash Table

Since Python 3.6 (and guaranteed in Python 3.7+), dictionaries preserve **insertion order** and consume 20% to 25% less memory thanks to the **Compact Dict** design invented by Raymond Hettinger.

### 3.1 Architecture: Indices Table + Entries Table
Traditional hash tables kept hash, key, and value in a single sparse array. The compact design decouples sparse indices from dense entries:

```
# Entries Table (Dense, sequentially appended):
entries = [
    [hash('tim'), 'tim', 29],      # index 0
    [hash('bob'), 'bob', 33],      # index 1
    [hash('ann'), 'ann', 22],      # index 2
]

# Indices Table (Sparse array of small integer offsets):
# Hash % table_size maps to an index in the entries table:
indices = [None, 1, None, 0, None, 2, None, None]
```

### 3.2 Collision Resolution: Open Addressing with Perturbation
CPython does not use separate chaining (linked lists). It uses **open addressing**.
When a hash collision occurs at index $j$, instead of simple linear probing ($j+1$), CPython uses a pseudo-random perturbation sequence:

$$j = ((5 \times j) + 1 + \text{perturb}) \pmod{\text{mask}}$$
$$\text{perturb} = \text{perturb} \gg 5$$

This formula ensures:
1. Every slot in the table is visited before any slot is repeated.
2. The sequence depends on all bits of the original 64-bit hash, avoiding primary clustering.

### 3.3 What Objects can be Dictionary Keys?
An object can be a dictionary key if and only if it is **hashable**:
1. Implements `__hash__()` returning a stable integer throughout its lifecycle.
2. Implements `__eq__()` for equality comparison on collision.
3. If `a == b`, then `hash(a) == hash(b)` **must** hold.

## 4. `collections.deque`: Double-Ended Queue

`deque` is implemented as a **doubly linked list of fixed-size blocks** (each block holds 62 elements on 64-bit platforms).

```
[Block 1 (62 items)] <---> [Block 2 (62 items)] <---> [Block 3 (62 items)]
      ^                                                     ^
   left side                                             right side
```

### Why use `deque`?
- **Pushes and Pops at both ends:** `append()`, `appendleft()`, `pop()`, `popleft()` run in strict **$\mathcal{O}(1)$ time** without resizing or shifting elements.
- **Thread Safety:** `append()`, `appendleft()`, `pop()`, `popleft()` are atomic and thread-safe in CPython.
- **Tradeoff:** Random indexing (`deque[i]`) is $\mathcal{O}(N)$ as it must traverse blocks.

## 5. `heapq`: Priority Queues

Python's `heapq` module provides a min-heap implementation based on a 0-indexed contiguous `list`.

### 5.1 Binary Heap Properties
For element at index $i$:
- **Parent index:** $(i - 1) // 2$
- **Left child index:** $2i + 1$
- **Right child index:** $2i + 2$
- **Heap Invariant:** `heap[parent] <= heap[child]` for all nodes.

### 5.2 Linear Time `heapify` ($\mathcal{O}(N)$ vs $\mathcal{O}(N \log N)$)
```python
import heapq

nums = [5, 7, 9, 1, 3]
heapq.heapify(nums)  # O(N) time!
```
- Calling `heappush` $N$ times takes $\mathcal{O}(N \log N)$.
- Calling `heapq.heapify(nums)` runs **Floyd's build-heap algorithm** starting from the lowest internal nodes up to the root, taking mathematical **$\mathcal{O}(N)$ time**.

### 5.3 Simulating a Max-Heap in Python
`heapq` is strictly a min-heap. To simulate a max-heap:
1. **Negate numerical keys:** Push `-val` onto the heap:
   ```python
   heapq.heappush(max_heap, -val)
   largest = -heapq.heappop(max_heap)
   ```
2. **Tuples with custom priorities:**
   ```python
   heapq.heappush(heap, (-priority, item))
   ```
3. **Inversion Wrapper Object:**
   ```python
   class MaxHeapItem:
       def __init__(self, val):
           self.val = val
       def __lt__(self, other):
           return self.val > other.val  # Inverted comparison!
   ```

## 6. `bisect`: Binary Search on Sequences

The `bisect` module implements binary search over sorted lists.

```python
import bisect

arr = [1, 2, 4, 4, 4, 6, 7]

# bisect_left: First index where x can be inserted to maintain sorted order
# (Equivalent to C++ std::lower_bound)
idx1 = bisect.bisect_left(arr, 4)   # Output: 2

# bisect_right: Index AFTER the last occurrence of x
# (Equivalent to C++ std::upper_bound)
idx2 = bisect.bisect_right(arr, 4)  # Output: 5
```

### Key Functions (Python 3.10+):
```python
# Search by transformed key (e.g. interval start times)
intervals = [[1, 5], [3, 7], [6, 9]]
idx = bisect.bisect_left(intervals, 3, key=lambda x: x[0])  # Output: 1
```

## 7. `collections.Counter` & `defaultdict`

### 7.1 `defaultdict`
Avoids explicit `if key not in d:` initialization checks:
```python
from collections import defaultdict

graph = defaultdict(list)
graph[u].append(v)  # Automatically initializes empty list if u is new!

counts = defaultdict(int)
counts[word] += 1   # Automatically initializes 0
```

### 7.2 `Counter`
Specialized dictionary for counting hashable elements:
```python
from collections import Counter

c = Counter("abracadabra")
# Top k most frequent elements in O(N log k) time:
top_2 = c.most_common(2)  # [('a', 5), ('b', 2)]

# Counter arithmetic:
c1 = Counter(a=3, b=1)
c2 = Counter(a=1, b=2)
print(c1 + c2)  # Counter({'a': 4, 'b': 3})
print(c1 & c2)  # Minimum of each: Counter({'a': 1, 'b': 1})
```
