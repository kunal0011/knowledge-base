# Chapter 01: Foundations & Classical Ciphers — Perfect Secrecy & Information Theory

> "To evaluate the security of a cryptosystem, we must assume that the adversary knows the algorithm being used. Secrecy must reside entirely in the key. When an encryption scheme achieves perfect secrecy, an intercepted ciphertext gives the attacker mathematically zero additional information about the plaintext."  
> — *Claude E. Shannon, Communication Theory of Secrecy Systems (1949)*

## 🏛️ 1. Classical Ciphers & The Illusion of Security

Early cryptography relied on clever linguistic manipulations:

```text
===================================================================================================
                               CLASSICAL CIPHER TAXONOMY
===================================================================================================

  [ Caesar / Shift Cipher ]
  Formula: C_i = (P_i + K) mod 26
  - Key space: |K| = 26.
  - Trivial brute-force: Try all 25 shifts; English plaintext emerges in under 2 seconds.

  [ Monoalphabetic Substitution ]
  Arbitrary permutation of the 26 alphabet letters.
  - Key space: |K| = 26! ≈ 4.03 x 10^26 (Larger than an 88-bit key!).
  - ⚠️ The Fallacy: A massive key space DOES NOT guarantee security!
  - Destroyed completely via Frequency Analysis.
```

### 1.1 Frequency Analysis: Exploiting Statistical Invariants
Natural human language is non-random. In English, the letter **E** appears with probability $\approx 12.7\%$, followed by **T** ($9.1\%$) and **A** ($8.2\%$). Digraphs like **TH**, **HE**, and **IN** occur with predictable regularity.

A monoalphabetic cipher simply maps $E \to \text{Symbol } X$. A simple histogram of letter counts in a 200-word ciphertext reveals the plaintext alphabet immediately.

---

### 1.2 Polyalphabetic Ciphers: The Vigenère Cipher
To defeat single-letter frequency analysis, Blaise de Vigenère introduced repeating keyword shifts:
$$C_i = (P_i + K_{i \pmod L}) \bmod 26$$
where $L$ is the length of the secret keyword.

#### Breaking Vigenère: The Kasiski Examination
If a 3-letter word (like "THE") aligns with the keyword at intervals that are multiples of $L$, identical ciphertext trigraphs appear at repeated distances $d_1, d_2, d_3$. The greatest common divisor $\gcd(d_1, d_2, d_3)$ reveals the secret key length $L$! Once $L$ is known, the ciphertext is partitioned into $L$ independent Caesar ciphers, solved trivially via frequency analysis.

## 📐 2. Claude Shannon's Information Theory & Entropy

In 1948, Claude Shannon founded Information Theory, providing the mathematical vocabulary for modern cryptography.

### 2.1 Information Entropy ($H(X)$)
**Entropy** measures the fundamental uncertainty or average information contained in a random variable $X$ taking values in $\mathcal{X}$:
$$H(X) = -\sum_{x \in \mathcal{X}} \Pr[X = x] \log_2 \Pr[X = x]$$

- For a deterministic constant ($P=1$): $H(X) = -1 \cdot \log_2(1) = 0\text{ bits}$ of entropy (zero randomness).
- For a fair 128-bit cryptographic key chosen uniformly at random:
  $$H(K) = -\sum_{i=1}^{2^{128}} \frac{1}{2^{128}} \log_2 \left(\frac{1}{2^{128}}\right) = 128\text{ bits of pure entropy!}$$

## 🛡️ 3. Shannon's Definition of Perfect Secrecy

Let an encryption scheme consist of three polynomial-time algorithms $(\text{Gen}, \text{Enc}, \text{Dec})$ defined over message space $\mathcal{M}$, key space $\mathcal{K}$, and ciphertext space $\mathcal{C}$.

### Formal Mathematical Definition
An encryption scheme has **Perfect Secrecy** if for every probability distribution over $\mathcal{M}$, every message $m \in \mathcal{M}$, and every ciphertext $c \in \mathcal{C}$ for which $\Pr[C = c] > 0$:
$$\Pr[M = m \mid C = c] = \Pr[M = m]$$
In terms of mutual information:
$$I(M; C) = H(M) - H(M \mid C) = 0$$
Observing the ciphertext $c$ provides the adversary **zero reduction in uncertainty** regarding the plaintext $m$. To an eavesdropper with infinite computational power, every plaintext is equally likely!

## 📜 4. The One-Time Pad (OTP) & Formal Proof of Perfect Secrecy

Invented by Gilbert Vernam in 1917, the **One-Time Pad (OTP)** encrypts an $n$-bit message $M$ using an $n$-bit random key $K$:
$$\text{Enc}_K(M) = M \oplus K = C$$
$$\text{Dec}_K(C) = C \oplus K = (M \oplus K) \oplus K = M$$

```text
===================================================================================================
                             THE PERFECT SECRECY OF THE ONE-TIME PAD
===================================================================================================

  Suppose the adversary intercepts 8-bit ciphertext C = 01101001:
  - Could the plaintext be M = "NO" (01001110)?
    YES! If the random key happened to be K = C ⊕ M = 00100111.
  - Could the plaintext be M = "GO" (01000111)?
    YES! If the random key happened to be K = C ⊕ M = 00101110.
  
  Because every possible key K exists with uniform probability 1 / 2^n,
  EVERY valid English message of length n is equally likely to be the plaintext!
```

### Formal Mathematical Proof
For any fixed ciphertext $c \in \{0, 1\}^n$ and any message $m \in \{0, 1\}^n$:
$$\Pr[C = c \mid M = m] = \Pr[M \oplus K = c \mid M = m] = \Pr[K = m \oplus c]$$
Because the key $K$ is chosen uniformly at random from $\{0, 1\}^n$, the probability that $K$ equals any specific string $m \oplus c$ is exactly $\frac{1}{2^n}$:
$$\Pr[C = c \mid M = m] = \frac{1}{2^n}$$
Notice that $\frac{1}{2^n}$ is completely independent of $m$! 

Applying Bayes' Theorem:
$$\Pr[M = m \mid C = c] = \frac{\Pr[C = c \mid M = m] \cdot \Pr[M = m]}{\Pr[C = c]} = \frac{\frac{1}{2^n} \cdot \Pr[M = m]}{\sum_{m' \in \mathcal{M}} \frac{1}{2^n} \Pr[M = m']} = \Pr[M = m]$$
$\blacksquare$ **The One-Time Pad is provably, unconditionally secure against an adversary with unbounded computational power.**

## ⚠️ 5. Shannon's Pessimistic Theorem & Real-World OTP Failures

If the One-Time Pad is mathematically unbreakable, why do we not use it for all digital communications?

### 5.1 Shannon's Lower Bound Theorem
Shannon proved mathematically that for **any** encryption scheme to achieve perfect secrecy:
$$|\mathcal{K}| \ge |\mathcal{M}| \implies \text{Key Length } \ge \text{ Message Length}$$
To encrypt a $100\text{ GB}$ hard drive with perfect secrecy, you must generate, transport, and protect a $100\text{ GB}$ random key! If you had a secure channel to transport a $100\text{ GB}$ secret key, you wouldn't need encryption in the first place—you could just send the message over that channel!

---

### 5.2 The "Two-Time Pad" Catastrophe (Key Reuse)
If a key $K$ is ever used to encrypt two different messages $M_1$ and $M_2$:
$$C_1 = M_1 \oplus K$$
$$C_2 = M_2 \oplus K$$
An adversary simply XORs the two ciphertexts together:
$$C_1 \oplus C_2 = (M_1 \oplus K) \oplus (M_2 \oplus K) = M_1 \oplus M_2$$
The key cancels out entirely! The attacker now possesses the XOR difference of two natural-language messages. Using statistical crib-dragging, both plaintexts can be completely reconstructed within minutes (the exact technique used in the **Venona project** to decode Soviet cables during the Cold War).

### 5.3 Complete Lack of Integrity (Malleability)
The One-Time Pad provides zero integrity. If an adversary flips bit $i$ of the ciphertext ($C'_i = C_i \oplus 1$), upon decryption:
$$M'_i = C'_i \oplus K_i = (C_i \oplus 1) \oplus K_i = M_i \oplus 1$$
The attacker flips the corresponding plaintext bit with $100\%$ certainty without knowing the key! (e.g., modifying a bank transfer from $\$1,000$ to $\$9,000$).
