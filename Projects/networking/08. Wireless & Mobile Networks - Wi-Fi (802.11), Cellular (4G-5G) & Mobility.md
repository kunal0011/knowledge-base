## 📡 1. Wireless Physics & The Radio Environment

Unlike guided media (fiber optics, copper coax) where electromagnetic waves are cleanly insulated, wireless transmission operates in an unguided, noisy broadcast medium subject to three physical limitations:

1. **Path Loss & Attenuation:** Electromagnetic signal strength degrades rapidly with distance following the inverse-square law ($P_r \propto \frac{P_t}{d^2}$ in free space, and $\frac{P_t}{d^4}$ in obstructed urban environments).
2. **Interference from Other Sources:** The unlicensed $2.4\text{ GHz}$ ISM band is simultaneously shared by Wi-Fi, Bluetooth, microwave ovens, and cordless phones.
3. **Multipath Fading:** Radio waves reflect off buildings, hills, and metal walls. Multiple delayed, out-of-phase copies of the same signal arrive at the receiver antenna, destructively canceling each other out.

```text
===================================================================================================
                             SNR VS. BER & ADAPTIVE MODULATION
===================================================================================================

  High SNR (Close to Access Point)          ──► High-Order Modulation: 256-QAM (8 bits/symbol)
  (Clean signal, low background noise)          Maximum Throughput!
  
  Low SNR (At edge of coverage / Behind wall)──► Low-Order Modulation: BPSK / QPSK (1-2 bits/sym)
  (Noisy signal, high error probability)        Robust error resistance, but lower speed!
```

## 📶 2. IEEE 802.11 Wi-Fi & CSMA/CA

In wired Ethernet, nodes use **CSMA/CD** (Collision Detection). Why is CSMA/CD physically impossible in wireless?
1. **Transmit vs. Receive Dynamic Range:** A wireless card transmits at $+20\text{ dBm}$ ($100\text{ mW}$) but receives incoming signals at $-80\text{ dBm}$ ($0.00001\text{ mW}$). A node's own transmission power completely deafens its receiver; it cannot detect a faint collision occurring simultaneously!
2. **The Hidden Terminal Problem:** Physical obstacles or distance prevent two nodes from hearing each other, even though their transmissions collide at the shared Access Point:

```text
===================================================================================================
                                 THE HIDDEN TERMINAL PROBLEM
===================================================================================================

       Node A (Out of range of C)                         Node C (Out of range of A)
       ┌──────────┐                                       ┌──────────┐
       │ Laptop A │                                       │ Laptop C │
       └────┬─────┘                                       └─────┬────┘
            │                                                   │
            │ Transmits to AP                                   │ Transmits to AP
            ▼                                                   ▼
       ┌─────────────────────────────────────────────────────────────┐
       │                 Wireless Access Point (AP)                  │
       │                   COLLISION OCCURS AT AP!                   │
       └─────────────────────────────────────────────────────────────┘
  - Node A senses channel: SILENT (Cannot hear C!)
  - Node C senses channel: SILENT (Cannot hear A!)
  - Both transmit simultaneously -> Collision at AP!
```

### 2.1 CSMA/CA (Collision Avoidance) with RTS/CTS

To prevent collisions, 802.11 employs **CSMA/CA** supplemented with virtual carrier sensing via **RTS/CTS (Request-to-Send / Clear-to-Send)**:

```text
===================================================================================================
                                      RTS/CTS RESERVATION FLOW
===================================================================================================

  Node A                                    Access Point (AP)                     Node C (Hidden)
    │                                              │                                     │
    │─── 1. RTS (Request to Send) ────────────────►│                                     │
    │    "Reserve channel for 500us"               │                                     │
    │                                              │                                     │
    │◄── 2. CTS (Clear to Send) ───────────────────┼────────────────────────────────────►│
    │    "Channel reserved for A for 500us"        │                                     │
    │                                              │                    Sets Network Allocation
    │                                              │                    Vector (NAV = 500us)!
    │─── 3. Transmits Data Frame ─────────────────►│                    (Node C remains silent!)
    │                                              │                                     │
    │◄── 4. ACK (Explicit Link Layer ACK) ─────────│                                     │
```

## 📱 3. Cellular Networks: 4G LTE vs. 5G New Radio (NR)

While Wi-Fi operates over short ranges ($< 50\text{ m}$) using unlicensed spectrum, cellular networks deliver nationwide coverage over licensed spectrum using cell towers (**Base Stations**).

```text
===================================================================================================
                               4G LTE VS. 5G CELLULAR ARCHITECTURES
===================================================================================================

 [ 4G LTE Architecture (Evolved Packet Core - EPC) ]
 User Device ──► eNodeB Base Station ──► SGW (Serving GW) ──► PGW (Packet GW) ──► Internet
                       │                      ▲
                       ▼                      │
             MME (Mobility Entity) ◄──► HSS (Home Subscriber Server)

 [ 5G Service-Based Architecture (SBA - Cloud Native HTTP/2) ]
 User Device ──► gNodeB (Massive MIMO) ──► UPF (User Plane Function) ──► Internet
                       │                         ▲
                       ▼                         │
            ┌────────────────────────────────────┴────────────────────────────────────┐
            │ 5G Core Control Plane (Microservices communicating via JSON/HTTP/2 APIs)│
            │ AMF (Access/Mobility)   SMF (Session Mgmt)   NRF (Discovery)  UDM (Auth)│
            └─────────────────────────────────────────────────────────────────────────┘
```

### 3.1 5G Technological Innovations
1. **Millimeter Wave (mmWave: $24\text{ to }100\text{ GHz}$):** Unprecedented spectrum yielding $10\text{ Gbps}$ download speeds, but limited to line-of-sight ($< 300\text{ meters}$) and blocked by rain or glass.
2. **Massive MIMO & Beamforming:** Instead of radiating radio energy in all directions, base stations coordinate grids of 64 or 128 antennas to steer narrow, focused radio beams directly at moving devices.
3. **Network Slicing:** Virtualizes the physical cellular network into independent, isolated logical slices tailored for specific SLAs:
   - **eMBB (Enhanced Mobile Broadband):** Massive bandwidth for 8K video streaming and VR.
   - **URLLC (Ultra-Reliable Low-Latency Communication):** Sub-millisecond latency for autonomous driving and remote surgery.
   - **mMTC (Massive Machine-Type Communication):** Low-power connectivity for millions of smart utility meters.

## 🚗 4. Mobility Management & Cellular Handovers

When a high-speed train travels at $300\text{ km/h}$, a connected passenger's smartphone moves between cellular base stations every few seconds.

```text
===================================================================================================
                                     CELLULAR HANDOVER SEQUENCE
===================================================================================================

  Smartphone                               Tower 1 (Old)                          Tower 2 (New)
      │                                          │                                      │
      │─── Periodic Signal Measurement (RSRP) ──►│                                      │
      │    "Tower 2 is stronger than Tower 1!"   │                                      │
      │                                          │─── Handover Request ────────────────►│
      │                                          │◄── Handover Request ACK ─────────────│
      │                                          │                                      │
      │◄── Handover Command (Switch to Tower 2) ─│                                      │
      │                                          ├─── Forwards buffered packets ───────►│
      │                                                                                 │
      │─── Reconnects to Tower 2 & Sends Handover Complete ────────────────────────────►│
      │                                                                                 │
      │◄══ Normal Data Flow Resumes with Zero Dropped Packets! ═════════════════════════╝
```
