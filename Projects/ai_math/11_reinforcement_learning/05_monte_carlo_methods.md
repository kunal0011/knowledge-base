# Monte Carlo Methods for Prediction and Control

---

## 1. Intuition & 101 Motivation

### Breaking Free from the Environment Model
In Dynamic Programming (Chapter 11.4), we assumed full, omniscient knowledge of the environment: the transition probability tensor $\mathcal{P}(s' \mid s, a)$ and reward function $\mathcal{R}(s, a)$.
In practice, this assumption is almost never satisfied:
- In complex board games (Go, Chess), writing down $\mathcal{P}$ requires enumerating $10^{170}$ states.
- In autonomous driving or robotics, the physical laws governing tire friction, wind turbulence, and sensor noise are intractable to model analytically.

**Monte Carlo (MC) methods** solve this problem by learning directly from **episodes of raw experience**:
1. The agent interacts with the world (or a simulator) and records trajectories: $(S_0, A_0, R_1, S_1, \dots, S_T)$.
2. Instead of computing expected values via Bellman expansion, the agent computes empirical sample averages of total observed returns $G_t$.
3. By the **Law of Large Numbers**, as the number of simulated episodes increases, the empirical average converges to the true expected value:
   $$\frac{1}{N} \sum_{i=1}^N G_t^{(i)} \xrightarrow{a.s.} \mathbb{E}_\pi[G_t \mid S_t = s] = V^\pi(s)$$

```
        DYNAMIC PROGRAMMING (Model-Based)              MONTE CARLO (Model-Free)
           (Full breadth, shallow depth)             (Sample trajectory, full depth)
                      S_t                                         S_t
                       ●                                           ●
                      / \                                          │ Action A_t
                     ○   ○                                         ○
                    / \ / \                                        │ Next State S_{t+1}
                   ●  ● ●  ●                                       ●
                   (All branches evaluated)                        │
                                                                   ▼ ...
                                                                   ● Terminal S_T
                                                          (Averages full return G_t)
```

## 2. Rigorous Mathematical Formulation

### 2.1 First-Visit vs. Every-Visit Monte Carlo Prediction

Let $\tau_1, \tau_2, \dots, \tau_M$ be $M$ independent episodes generated by following policy $\pi$.

#### 1. First-Visit Monte Carlo (FVMC)
Estimate $V^\pi(s)$ by averaging returns following the **first occurrence** of state $s$ within each episode:
$$V_M(s) \equiv \frac{\sum_{m=1}^M G^{(m)}(s) \cdot \mathbb{I}(\text{first visit to } s \text{ in episode } m)}{\sum_{m=1}^M \mathbb{I}(\text{first visit to } s \text{ in episode } m)}$$
- **Unbiased Estimator:** Each episode contributes at most one independent, identically distributed return sample:
  $$\mathbb{E}\left[ V_M(s) \right] = V^\pi(s)$$
- **Variance:** Decreases as $\mathcal{O}\left(\frac{1}{M}\right)$ by standard central limit theorem.

#### 2. Every-Visit Monte Carlo (EVMC)
Averages returns following **every occurrence** of state $s$ within each episode:
- For finite samples, returns within the same episode are correlated, introducing finite-sample bias.
- However, EVMC is **consistent** ($V_M(s) \to V^\pi(s)$ as $M \to \infty$) and frequently achieves lower mean squared error (MSE) on small datasets due to utilizing more data points.

---

### 2.2 Monte Carlo Control: Learning Action-Values $Q(s, a)$

Why can't we use $V(s)$ alone for model-free control?
In Dynamic Programming, we extracted the optimal policy via:
$$\pi'(s) = \operatorname{argmax}_a \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$$
In a model-free setting, we do **not** know $\mathcal{P}(s' \mid s, a)$! Even if we have the exact values $V(s')$, we cannot evaluate which action leads to which state.

Therefore, model-free control **must learn action-values $Q(s, a)$ directly**:
$$\pi'(s) = \operatorname{argmax}_{a \in \mathcal{A}} Q(s, a)$$
Once $Q(s, a)$ is learned, policy improvement requires **zero knowledge of environment dynamics**!

#### The Exploration Challenge: Monte Carlo with Exploring Starts (MCES)
If policy $\pi$ is deterministic, many action choices will never be tried. To ensure every state-action pair is visited infinitely often:
- **Exploring Starts Assumption:** Every episode begins by selecting state $S_0$ and action $A_0$ uniformly at random from $\mathcal{S} \times \mathcal{A}$, ensuring all pairs have non-zero probability of being sampled.

---

### 2.3 On-Policy $\epsilon$-Soft Control

In real physical systems, Exploring Starts cannot be guaranteed (a car cannot randomly spawn at 100 mph facing a wall).
We eliminate exploring starts by enforcing **On-Policy $\epsilon$-Soft Policies**:
$$\pi(a \mid s) \ge \frac{\epsilon}{|\mathcal{A}|}, \quad \forall a \in \mathcal{A}$$

#### The $\epsilon$-Greedy Policy Formulation
$$a^* = \operatorname{argmax}_{a} Q(s, a)$$
$$\pi(a \mid s) = \begin{cases} 1 - \epsilon + \frac{\epsilon}{|\mathcal{A}|} & \text{if } a = a^* \\ \frac{\epsilon}{|\mathcal{A}|} & \text{if } a \ne a^* \end{cases}$$

**Theorem (Policy Improvement under $\epsilon$-Greedy):**
For any $\epsilon$-soft policy $\pi$, the $\epsilon$-greedy policy $\pi'$ formed with respect to $Q^\pi$ satisfies:
$$V^{\pi'}(s) \ge V^\pi(s), \quad \forall s \in \mathcal{S}$$
The policy monotonically improves toward the optimal $\epsilon$-soft policy!

---

### 2.4 Off-Policy Monte Carlo & Importance Sampling

#### The Dilemma of On-Policy Exploration
An on-policy agent optimizes a compromised objective: it does not learn the *truly optimal* policy $\pi^*$; it learns the best *stochastic compromise* policy that explores by $\epsilon$.
To learn the true optimal deterministic policy $\pi^*$ while still exploring, we use **Off-Policy Learning**:
- **Target Policy $\pi(a \mid s)$:** The policy we want to evaluate and optimize (e.g., greedy $\pi^*$).
- **Behavior Policy $b(a \mid s)$:** The exploratory policy generating the trajectory data (e.g., $\epsilon$-soft).

**Coverage Assumption:**
$$\pi(a \mid s) > 0 \implies b(a \mid s) > 0, \quad \forall s, a$$

#### First-Principles Derivation of the Importance Sampling Ratio
We observe trajectory $\tau = (S_t, A_t, S_{t+1}, \dots, S_T)$ generated under behavior policy $b$.
The probability of this trajectory occurring under policy $\pi$ is:
$$\mathbb{P}(\tau \mid \pi) = \prod_{k=t}^{T-1} \pi(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)$$
The probability of the same trajectory occurring under behavior policy $b$ is:
$$\mathbb{P}(\tau \mid b) = \prod_{k=t}^{T-1} b(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)$$

The **Importance Sampling Ratio** $\rho_{t:T-1}$ is the likelihood ratio of the trajectory under the two policies:
$$\mathbf{\rho_{t:T-1} \equiv \frac{\mathbb{P}(\tau \mid \pi)}{\mathbb{P}(\tau \mid b)} = \frac{\prod_{k=t}^{T-1} \pi(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)}{\prod_{k=t}^{T-1} b(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}}$$

> **Key Theoretical Elegance:** The unknown environment dynamics $\mathcal{P}(S_{k+1} \mid S_k, A_k)$ appear identically in numerator and denominator and **cancel out completely**! We can re-weight trajectories across different policies without knowing the environment transition model!

---

### 2.5 Ordinary vs. Weighted Importance Sampling

Given $M$ trajectories with returns $G_t^{(m)}$ and importance weights $\rho_m$:

#### 1. Ordinary Importance Sampling (OIS)
$$V_{\text{OIS}}(s) \equiv \frac{1}{M} \sum_{m=1}^M \rho_m G_t^{(m)}$$
- **Unbiased:** $\mathbb{E}[V_{\text{OIS}}(s)] = V^\pi(s)$.
- **Catastrophic Variance:** Because $\rho_m = \prod_k \frac{\pi}{b}$ is a product of ratios, the variance can easily be **infinite** even on simple bounded tasks!

#### 2. Weighted Importance Sampling (WIS)
$$V_{\text{WIS}}(s) \equiv \frac{\sum_{m=1}^M \rho_m G_t^{(m)}}{\sum_{m=1}^M \rho_m}$$
(defined as $0$ if denominator is $0$).
- **Biased for Finite $M$:** $\mathbb{E}[V_{\text{WIS}}] \ne V^\pi(s)$ (bias decays as $\mathcal{O}(1/M)$).
- **Bounded Variance:** For $M = 1$, $V_{\text{WIS}}(s) = \frac{\rho_1 G_1}{\rho_1} = G_1$, bounded strictly by the reward range regardless of $\rho_1$!
In practice, **Weighted Importance Sampling is always preferred**.

---

### 2.6 Incremental Weighted Importance Sampling

To evaluate actions incrementally without storing trajectory lists, let $W_k = \rho_k$ be the importance weight of episode $k$, and let $C_n = \sum_{k=1}^n W_k$ be the running cumulative weight.
The incremental update rule for $Q_n$ is:
$$\mathbf{Q_{n+1} = Q_n + \frac{W_n}{C_n} \left( G_n - Q_n \right)}, \quad \text{where } C_n = C_{n-1} + W_n$$

## 3. Geometric & Physical Interpretation

### Trajectory Measure Warping
Consider the space of all possible trajectory paths $\Omega$:
1. The behavior policy $b$ spreads probability mass broadly across the trajectory simplex to ensure diverse exploration.
2. The target policy $\pi$ concentrates mass on a narrow, high-reward manifold.
3. The importance weight $\rho(\tau) = \frac{d\mathbb{P}_\pi}{d\mathbb{P}_b}(\tau)$ acts as the **Radon-Nikodym derivative** that mathematically warps the empirical measure induced by $b$ into the true target measure of $\pi$.

## 4. Real-World Analogy

### The Flight Simulator vs. The Formula 1 Pilot
- **Dynamic Programming:** A mechanical engineer with the full Blueprint CAD file of an engine calculating optimal fuel flow on paper using thermodynamic formulas.
- **Monte Carlo:** A pilot getting into a flight simulator, flying 100 complete simulated crash-or-land missions, and averaging the fuel efficiency of the flights that successfully touched down.
- **Importance Sampling (Coach & Student):** A student pilot (Behavior Policy $b$) flies randomly to learn. A master flight instructor (Target Policy $\pi$) watches the flight recording and calculates: *"If an expert pilot had flown this exact gust-of-wind scenario, what would the payout have been?"*

### 5.2 Concrete Toy Setup

Let $\mathcal{S} = \{S_1, S_2, \text{Terminal}\}$, $\mathcal{A} = \{a_1, a_2\}$, $\gamma = 1.0$.

#### Policies:
- **Target Policy $\pi$:** Always selects action $a_1$:
  $$\pi(a_1 \mid S_1) = 1.0, \quad \pi(a_2 \mid S_1) = 0.0$$
  $$\pi(a_1 \mid S_2) = 1.0, \quad \pi(a_2 \mid S_2) = 0.0$$
- **Behavior Policy $b$:** Equal 50-50 random selection:
  $$b(a_1 \mid S_1) = 0.5, \quad b(a_2 \mid S_1) = 0.5$$
  $$b(a_1 \mid S_2) = 0.5, \quad b(a_2 \mid S_2) = 0.5$$

We observe $M = 2$ complete episodes generated under behavior policy $b$.

---

### 5.3 Episode Trajectories & Return Calculations

#### Episode 1 ($\tau_1$):
$$\tau_1 = \left( S_1, a_1, R_1 = 2.0, \quad S_2, a_1, R_2 = 4.0, \quad \text{Terminal} \right)$$
- Return from $S_1$: $G_0^{(1)} = R_1 + R_2 = 2.0 + 4.0 = \mathbf{6.0000}$
- Return from $S_2$: $G_1^{(1)} = R_2 = \mathbf{4.0000}$

**Importance Sampling Ratio for Episode 1 from $S_1$:**
$$\rho_1 = \left( \frac{\pi(a_1 \mid S_1)}{b(a_1 \mid S_1)} \right) \times \left( \frac{\pi(a_1 \mid S_2)}{b(a_1 \mid S_2)} \right) = \left( \frac{1.0}{0.5} \right) \times \left( \frac{1.0}{0.5} \right) = 2.0 \times 2.0 = \mathbf{4.0000}$$

#### Episode 2 ($\tau_2$):
$$\tau_2 = \left( S_1, a_1, R_1 = 1.0, \quad S_2, a_2, R_2 = 0.0, \quad \text{Terminal} \right)$$
- Return from $S_1$: $G_0^{(2)} = R_1 + R_2 = 1.0 + 0.0 = \mathbf{1.0000}$
- Return from $S_2$: $G_1^{(2)} = R_2 = \mathbf{0.0000}$

**Importance Sampling Ratio for Episode 2 from $S_1$:**
$$\rho_2 = \left( \frac{\pi(a_1 \mid S_1)}{b(a_1 \mid S_1)} \right) \times \left( \frac{\pi(a_2 \mid S_2)}{b(a_2 \mid S_2)} \right) = \left( \frac{1.0}{0.5} \right) \times \left( \frac{0.0}{0.5} \right) = 2.0 \times 0.0 = \mathbf{0.0000}$$
(Because action $a_2$ would **never** be taken by target policy $\pi$, this trajectory has probability 0 under $\pi$, so $\rho_2 = 0$!).

---

### 5.4 Step 1: On-Policy Sample Averages for Behavior Policy $b$

If we simply wanted to evaluate behavior policy $b(s)$ on state $S_1$:
$$V^b(S_1) = \frac{G_0^{(1)} + G_0^{(2)}}{2} = \frac{6.0000 + 1.0000}{2} = \frac{7.0000}{2} = \mathbf{3.5000}$$

---

### 5.5 Step 2: Off-Policy Value Estimation for Target Policy $\pi$

#### 1. Ordinary Importance Sampling ($V_{\text{OIS}}$)
$$V_{\text{OIS}}(S_1) = \frac{1}{M} \sum_{m=1}^2 \rho_m G^{(m)} = \frac{\rho_1 G^{(1)} + \rho_2 G^{(2)}}{2}$$
$$= \frac{(4.0000 \times 6.0000) + (0.0000 \times 1.0000)}{2} = \frac{24.0000 + 0.0000}{2} = \frac{24.0000}{2} = \mathbf{12.0000}$$

#### 2. Weighted Importance Sampling ($V_{\text{WIS}}$)
$$V_{\text{WIS}}(S_1) = \frac{\sum_{m=1}^2 \rho_m G^{(m)}}{\sum_{m=1}^2 \rho_m} = \frac{\rho_1 G^{(1)} + \rho_2 G^{(2)}}{\rho_1 + \rho_2}$$
$$= \frac{(4.0000 \times 6.0000) + (0.0000 \times 1.0000)}{4.0000 + 0.0000} = \frac{24.0000}{4.0000} = \mathbf{6.0000}$$

**Profound Insight from Hand Calculation:**
- Target policy $\pi$ deterministically takes action sequence $(a_1, a_1)$.
- Episode 1 is the **only** trajectory that followed target policy $\pi$'s choices, yielding return $G = 6.0$.
- **Weighted IS** correctly normalized the weight and produced $V_{\text{WIS}} = \mathbf{6.0000}$ (the exact true value of that path!).
- **Ordinary IS** scaled by $1/M = 1/2$, artificially doubling the estimated return to $\mathbf{12.0000}$ due to weight explosion!

## 6. Solved Illustrations

### Illustration 1: Infinite Variance of Ordinary Importance Sampling
**Problem (Sutton & Barto Counterexample):**
Consider a 1-state MDP. State $S$ has two actions: `back` ($a_1$) and `end` ($a_2$).
- Action `back` returns to $S$ with reward $0$.
- Action `end` terminates with reward $+1$.
Target policy $\pi(\text{back} \mid S) = 1.0$. (Target policy loops forever, return is $0$).
Behavior policy $b(\text{back} \mid S) = 0.5, b(\text{end} \mid S) = 0.5$.
Prove that the second moment (and hence the variance) of the Ordinary Importance Sampling estimator is **infinite**.
**Solution:**
A trajectory consisting of $k$ `back` actions followed by `end` has return $G = 1$ (if undiscounted).
Probability under $b$: $\mathbb{P}_b = (0.5)^k \times 0.5 = (0.5)^{k+1}$.
Probability under $\pi$: For any `end` action, $\pi(\text{end}) = 0$. Thus, $\rho = 0$ for all terminating episodes!
If reward is given upon termination, consider an episode where termination yields $1$:
Importance ratio: $\rho = \frac{1.0^k \times 0}{0.5^{k+1}} = 0$.
Now consider target policy $\pi(\text{back}) = 1.0$ and reward on `end` with $\gamma < 1$:
The second moment of the estimator $X = \rho G$ is:
$$\mathbb{E}_b[X^2] = \sum_{k=0}^\infty \mathbb{P}_b(\tau_k) \cdot \left( \rho_k G_k \right)^2 = \sum_{k=0}^\infty (0.5)^{k+1} \left( \frac{1.0^k}{0.5^k} \times 1 \right)^2 = \sum_{k=0}^\infty \frac{1}{2^{k+1}} \left( 2^k \right)^2 = \sum_{k=0}^\infty \frac{4^k}{2^{k+1}} = \frac{1}{2} \sum_{k=0}^\infty 2^k = +\infty$$
The second moment diverges to $+\infty$!
Even after millions of samples, Ordinary Importance Sampling will never settle down, experiencing massive periodic explosive spikes. Weighted Importance Sampling completely eliminates this pathology! $\blacksquare$

## 7. Deep Learning Connection & Application

### 1. AlphaGo & MCTS Monte Carlo Rollouts (Silver et al., Nature 2016)
In the original AlphaGo, the leaf evaluation of Monte Carlo Tree Search used a hybrid:
$$V(s_L) = (1 - \lambda) v_\theta(s_L) + \lambda G_L$$
where $G_L$ was the outcome of a **fast Monte Carlo rollout** to the end of the game using a lightweight policy. This pure Monte Carlo sample prevented the neural network $v_\theta$ from hallucinating blind spots!

### 2. REINFORCE as Monte Carlo Policy Optimization
The foundational Policy Gradient algorithm (Chapter 11.13) is an on-policy Monte Carlo method:
$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^T G_t \nabla_\theta \log \pi_\theta(A_t \mid S_t) \right]$$
It uses full episodic Monte Carlo returns $G_t$ to compute unbiased gradient estimates without an environment model.
