# Monte Carlo Methods for Prediction and Control

---

## 1. Intuition & 101 Motivation

### Breaking Free from the Environment Model
In Dynamic Programming (Chapter 11.4), we assumed full, omniscient knowledge of the environment: the transition probability tensor $\mathcal{P}(s' \mid s, a)$ and reward function $\mathcal{R}(s, a)$.
In practice, this assumption is almost never satisfied:
- In complex board games (Go, Chess), writing down $\mathcal{P}$ requires enumerating $10^{170}$ states.
- In autonomous driving or robotics, the physical laws governing tire friction, wind turbulence, and sensor noise are intractable to model analytically.

**Monte Carlo (MC) methods** solve this problem by learning directly from **episodes of raw experience**:
1. The agent interacts with the world (or a simulator) and records trajectories: $(S_0, A_0, R_1, S_1, \dots, S_T)$.
2. Instead of computing expected values via Bellman expansion, the agent computes empirical sample averages of total observed returns $G_t$.
3. By the **Law of Large Numbers**, as the number of simulated episodes increases, the empirical average converges to the true expected value:
   $$\frac{1}{N} \sum_{i=1}^N G_t^{(i)} \xrightarrow{a.s.} \mathbb{E}_\pi[G_t \mid S_t = s] = V^\pi(s)$$

```
        DYNAMIC PROGRAMMING (Model-Based)              MONTE CARLO (Model-Free)
           (Full breadth, shallow depth)             (Sample trajectory, full depth)
                      S_t                                         S_t
                       ●                                           ●
                      / \                                          │ Action A_t
                     ○   ○                                         ○
                    / \ / \                                        │ Next State S_{t+1}
                   ●  ● ●  ●                                       ●
                   (All branches evaluated)                        │
                                                                   ▼ ...
                                                                   ● Terminal S_T
                                                          (Averages full return G_t)
```

## 2. Rigorous Mathematical Formulation

### 2.1 First-Visit vs. Every-Visit Monte Carlo Prediction

Let $\tau_1, \tau_2, \dots, \tau_M$ be $M$ independent episodes generated by following policy $\pi$.

#### 1. First-Visit Monte Carlo (FVMC)
Estimate $V^\pi(s)$ by averaging returns following the **first occurrence** of state $s$ within each episode:
$$V_M(s) \equiv \frac{\sum_{m=1}^M G^{(m)}(s) \cdot \mathbb{I}(\text{first visit to } s \text{ in episode } m)}{\sum_{m=1}^M \mathbb{I}(\text{first visit to } s \text{ in episode } m)}$$
- **Unbiased Estimator:** Each episode contributes at most one independent, identically distributed return sample:
  $$\mathbb{E}\left[ V_M(s) \right] = V^\pi(s)$$
- **Variance:** Decreases as $\mathcal{O}\left(\frac{1}{M}\right)$ by standard central limit theorem.

#### 2. Every-Visit Monte Carlo (EVMC)
Averages returns following **every occurrence** of state $s$ within each episode:
- For finite samples, returns within the same episode are correlated, introducing finite-sample bias.
- However, EVMC is **consistent** ($V_M(s) \to V^\pi(s)$ as $M \to \infty$) and frequently achieves lower mean squared error (MSE) on small datasets due to utilizing more data points.

---

### 2.2 Monte Carlo Control: Learning Action-Values $Q(s, a)$

Why can't we use $V(s)$ alone for model-free control?
In Dynamic Programming, we extracted the optimal policy via:
$$\pi'(s) = \operatorname{argmax}_a \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$$
In a model-free setting, we do **not** know $\mathcal{P}(s' \mid s, a)$! Even if we have the exact values $V(s')$, we cannot evaluate which action leads to which state.

Therefore, model-free control **must learn action-values $Q(s, a)$ directly**:
$$\pi'(s) = \operatorname{argmax}_{a \in \mathcal{A}} Q(s, a)$$
Once $Q(s, a)$ is learned, policy improvement requires **zero knowledge of environment dynamics**!

#### The Exploration Challenge: Monte Carlo with Exploring Starts (MCES)
If policy $\pi$ is deterministic, many action choices will never be tried. To ensure every state-action pair is visited infinitely often:
- **Exploring Starts Assumption:** Every episode begins by selecting state $S_0$ and action $A_0$ uniformly at random from $\mathcal{S} \times \mathcal{A}$, ensuring all pairs have non-zero probability of being sampled.

---

### 2.3 On-Policy $\epsilon$-Soft Control

In real physical systems, Exploring Starts cannot be guaranteed (a car cannot randomly spawn at 100 mph facing a wall).
We eliminate exploring starts by enforcing **On-Policy $\epsilon$-Soft Policies**:
$$\pi(a \mid s) \ge \frac{\epsilon}{|\mathcal{A}|}, \quad \forall a \in \mathcal{A}$$

#### The $\epsilon$-Greedy Policy Formulation
$$a^* = \operatorname{argmax}_{a} Q(s, a)$$
$$\pi(a \mid s) = \begin{cases} 1 - \epsilon + \frac{\epsilon}{|\mathcal{A}|} & \text{if } a = a^* \\ \frac{\epsilon}{|\mathcal{A}|} & \text{if } a \ne a^* \end{cases}$$

**Theorem (Policy Improvement under $\epsilon$-Greedy):**
For any $\epsilon$-soft policy $\pi$, the $\epsilon$-greedy policy $\pi'$ formed with respect to $Q^\pi$ satisfies:
$$V^{\pi'}(s) \ge V^\pi(s), \quad \forall s \in \mathcal{S}$$
The policy monotonically improves toward the optimal $\epsilon$-soft policy!

### 2.4 Off-Policy Monte Carlo & Importance Sampling

#### The Dilemma of On-Policy Exploration
An on-policy agent optimizes a compromised objective: it does not learn the *truly optimal* policy $\pi^*$; it learns the best *stochastic compromise* policy that explores by $\epsilon$.
To learn the true optimal deterministic policy $\pi^*$ while still exploring, we use **Off-Policy Learning**:
- **Target Policy $\pi(a \mid s)$:** The policy we want to evaluate and optimize (e.g., greedy $\pi^*$).
- **Behavior Policy $b(a \mid s)$:** The exploratory policy generating the trajectory data (e.g., $\epsilon$-soft).

**Coverage Assumption:**
$$\pi(a \mid s) > 0 \implies b(a \mid s) > 0, \quad \forall s, a$$

#### First-Principles Derivation of the Importance Sampling Ratio
We observe trajectory $\tau = (S_t, A_t, S_{t+1}, \dots, S_T)$ generated under behavior policy $b$.
The probability of this trajectory occurring under policy $\pi$ is:
$$\mathbb{P}(\tau \mid \pi) = \prod_{k=t}^{T-1} \pi(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)$$
The probability of the same trajectory occurring under behavior policy $b$ is:
$$\mathbb{P}(\tau \mid b) = \prod_{k=t}^{T-1} b(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)$$

The **Importance Sampling Ratio** $\rho_{t:T-1}$ is the likelihood ratio of the trajectory under the two policies:
$$\mathbf{\rho_{t:T-1} \equiv \frac{\mathbb{P}(\tau \mid \pi)}{\mathbb{P}(\tau \mid b)} = \frac{\prod_{k=t}^{T-1} \pi(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)}{\prod_{k=t}^{T-1} b(A_k \mid S_k) \mathcal{P}(S_{k+1} \mid S_k, A_k)} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}}$$

> **Key Theoretical Elegance:** The unknown environment dynamics $\mathcal{P}(S_{k+1} \mid S_k, A_k)$ appear identically in numerator and denominator and **cancel out completely**! We can re-weight trajectories across different policies without knowing the environment transition model!

---

### 2.5 Ordinary vs. Weighted Importance Sampling

Given $M$ trajectories with returns $G_t^{(m)}$ and importance weights $\rho_m$:

#### 1. Ordinary Importance Sampling (OIS)
$$V_{\text{OIS}}(s) \equiv \frac{1}{M} \sum_{m=1}^M \rho_m G_t^{(m)}$$
- **Unbiased:** $\mathbb{E}[V_{\text{OIS}}(s)] = V^\pi(s)$.
- **Catastrophic Variance:** Because $\rho_m = \prod_k \frac{\pi}{b}$ is a product of ratios, the variance can easily be **infinite** even on simple bounded tasks!

#### 2. Weighted Importance Sampling (WIS)
$$V_{\text{WIS}}(s) \equiv \frac{\sum_{m=1}^M \rho_m G_t^{(m)}}{\sum_{m=1}^M \rho_m}$$
(defined as $0$ if denominator is $0$).
- **Biased for Finite $M$:** $\mathbb{E}[V_{\text{WIS}}] \ne V^\pi(s)$ (bias decays as $\mathcal{O}(1/M)$).
- **Bounded Variance:** For $M = 1$, $V_{\text{WIS}}(s) = \frac{\rho_1 G_1}{\rho_1} = G_1$, bounded strictly by the reward range regardless of $\rho_1$!
In practice, **Weighted Importance Sampling is always preferred**.

---

### 2.6 Incremental Weighted Importance Sampling

To evaluate actions incrementally without storing trajectory lists, let $W_k = \rho_k$ be the importance weight of episode $k$, and let $C_n = \sum_{k=1}^n W_k$ be the running cumulative weight.
The incremental update rule for $Q_n$ is:
$$\mathbf{Q_{n+1} = Q_n + \frac{W_n}{C_n} \left( G_n - Q_n \right)}, \quad \text{where } C_n = C_{n-1} + W_n$$

### 2.7 First-Principles Mathematical Derivations

#### Derivation 11.5.1: Unbiasedness of First-Visit Monte Carlo & Almost Sure Convergence via the Strong Law of Large Numbers

##### Problem Statement & Goal
Let $\tau_1, \tau_2, \dots, \tau_M$ be $M$ independent episodic trajectories generated by following policy $\pi$ in an MDP $\mathcal{M}$. For any state $s \in \mathcal{S}$, let $G_i(s)$ denote the discounted return following the first visit to state $s$ in episode $i$ (for episodes where $s$ is visited at least once). Let $N(s)$ be the number of episodes containing at least one visit to $s$.
The First-Visit Monte Carlo (FVMC) estimator is:
$$\hat{V}_M(s) \equiv \frac{1}{N(s)} \sum_{i=1}^{N(s)} G_i(s)$$
We prove:
1. Conditional on $N(s) \ge 1$, $\hat{V}_M(s)$ is a strictly unbiased estimator of $V^\pi(s)$:
   $$\mathbb{E}\left[ \hat{V}_M(s) \;\middle|\; N(s) = k \right] = V^\pi(s)$$
2. The estimator variance is inversely proportional to sample count:
   $$\operatorname{Var}\left( \hat{V}_M(s) \;\middle|\; N(s) = k \right) = \frac{\sigma^2(s)}{k}$$
   where $\sigma^2(s) = \operatorname{Var}_\pi(G_t \mid S_t = s)$.
3. By Kolmogorov's Strong Law of Large Numbers, $\hat{V}_M(s)$ converges almost surely to $V^\pi(s)$:
   $$\mathbb{P}\left( \lim_{M \to \infty} \hat{V}_M(s) = V^\pi(s) \right) = 1$$

##### Explicit Assumptions
1. Episodes terminate in finite time with probability 1 (proper Markov chains with absorbing states, or discounted continuing with horizon truncation).
2. The return variance is bounded: $\sigma^2(s) \equiv \operatorname{Var}_\pi(G_t \mid S_t = s) \le \frac{R_{\max}^2}{(1 - \gamma)^2} < \infty$.
3. Episodes $\tau_1, \tau_2, \dots$ are mutually independent and identically distributed (i.i.d.).
4. The policy $\pi$ visits state $s$ with positive probability: $p_s \equiv \mathbb{P}(\tau \text{ visits } s) > 0$.

##### Underlying Intuition
Because First-Visit MC extracts only the very first occurrence of state $s$ in each episode, each episode produces at most one sample return. Since each episode is simulated independently starting from the initial distribution or an exploring start, these first-visit returns are independent random variables drawn from the exact same conditional distribution $\mathbb{P}_\pi(G_t \mid S_t = s)$. Taking an empirical average of i.i.d. random variables yields an unbiased estimator whose variance shrinks strictly as $1/N$.

##### End-to-End Mathematical Derivation

**Step 1: Conditional Independence of Sample Returns**
Let $E_i$ be the indicator variable that episode $i$ visits state $s$: $E_i = \mathbb{I}(s \in \tau_i)$.
Since episodes are generated independently:
$$E_1, E_2, \dots, E_M \stackrel{\text{i.i.d.}}{\sim} \text{Bernoulli}(p_s), \quad \text{where } p_s = \mathbb{P}_\pi(s \in \tau) > 0$$
The total number of visited episodes is $N(s) = \sum_{i=1}^M E_i \sim \text{Binomial}(M, p_s)$.
For any episode $i$ where $E_i = 1$, let $t_i \equiv \min \{ t \ge 0 \mid S_t = s \}$ denote the first-visit time.
By the Markov Property (Derivation 11.2.1), the future trajectory after time $t_i$ depends solely on state $S_{t_i} = s$ and policy $\pi$, being conditionally independent of the historical path leading to $s$.
Therefore, conditional on $E_i = 1$:
$$G_i(s) \equiv \sum_{k=0}^{T_i - t_i - 1} \gamma^k R_{t_i + k + 1} \stackrel{\text{i.i.d.}}{\sim} \mathbb{P}_\pi\left( G \;\middle|\; S = s \right)$$
with true mean $\mathbb{E}_\pi[G_i(s)] = V^\pi(s)$ and variance $\operatorname{Var}_\pi(G_i(s)) = \sigma^2(s) < \infty$.

**Step 2: Proof of Unbiasedness**
Condition on having observed $N(s) = k \ge 1$ episodes visiting state $s$:
$$\begin{aligned}
\mathbb{E}\left[ \hat{V}_M(s) \;\middle|\; N(s) = k \right] &= \mathbb{E}\left[ \frac{1}{k} \sum_{i=1}^k G_i(s) \;\middle|\; N(s) = k \right] \\
&= \frac{1}{k} \sum_{i=1}^k \mathbb{E}\left[ G_i(s) \right] = \frac{1}{k} \sum_{i=1}^k V^\pi(s) = \frac{1}{k} \left( k V^\pi(s) \right) = V^\pi(s)
\end{aligned}$$
Taking the expectation over all possible values of $k \ge 1$:
$$\mathbb{E}\left[ \hat{V}_M(s) \;\middle|\; N(s) \ge 1 \right] = \sum_{k=1}^M \mathbb{P}(N(s) = k \mid N(s) \ge 1) V^\pi(s) = V^\pi(s)$$
The estimator is strictly unbiased.

**Step 3: Variance of the Estimator**
Because the returns $\{G_i(s)\}_{i=1}^k$ are conditionally independent given $N(s) = k$:
$$\begin{aligned}
\operatorname{Var}\left( \hat{V}_M(s) \;\middle|\; N(s) = k \right) &= \operatorname{Var}\left( \frac{1}{k} \sum_{i=1}^k G_i(s) \right) \\
&= \frac{1}{k^2} \sum_{i=1}^k \operatorname{Var}(G_i(s)) = \frac{1}{k^2} \left( k \sigma^2(s) \right) = \frac{\sigma^2(s)}{k}
\end{aligned}$$
As $k \to \infty$, the variance vanishes at rate $\mathcal{O}(1/k)$.

**Step 4: Almost Sure Convergence via SLLN**
Because $p_s > 0$, by the Strong Law of Large Numbers for Bernoulli trials:
$$\lim_{M \to \infty} \frac{N(s)}{M} = p_s > 0 \quad \text{almost surely}$$
which implies $\lim_{M \to \infty} N(s) = \infty$ almost surely.
Applying Kolmogorov's Strong Law of Large Numbers to the i.i.d. sequence of bounded-variance random variables $G_1(s), G_2(s), \dots$:
$$\mathbb{P}\left( \lim_{k \to \infty} \frac{1}{k} \sum_{i=1}^k G_i(s) = \mathbb{E}[G_1(s)] = V^\pi(s) \right) = 1$$
Therefore:
$$\hat{V}_M(s) \xrightarrow{a.s.} V^\pi(s) \quad \text{as } M \to \infty \quad \blacksquare$$

#### Derivation 11.5.2: The $\epsilon$-Greedy Policy Improvement Theorem

##### Problem Statement & Goal
Let $\pi$ be an arbitrary $\epsilon$-soft policy with action space $|\mathcal{A}| = m$, meaning $\pi(a \mid s) \ge \frac{\epsilon}{m}$ for all $a \in \mathcal{A}$.
Define the $\epsilon$-greedy policy $\pi'$ with respect to action-values $Q^\pi(s, a)$ by:
$$\pi'(a \mid s) \equiv \begin{cases} 1 - \epsilon + \frac{\epsilon}{m} & \text{if } a = a^* \equiv \arg\max_{a' \in \mathcal{A}} Q^\pi(s, a') \\ \frac{\epsilon}{m} & \text{if } a \ne a^* \end{cases}$$
We prove that:
1. The expected action value under $\pi'$ weakly dominates the state value under $\pi$ for all states:
   $$q^\pi(s, \pi'(s)) \equiv \sum_{a \in \mathcal{A}} \pi'(a \mid s) Q^\pi(s, a) \ge V^\pi(s), \quad \forall s \in \mathcal{S}$$
2. By the Policy Improvement Theorem, the entire value function improves monotonically:
   $$V^{\pi'}(s) \ge V^\pi(s), \quad \forall s \in \mathcal{S}$$

##### Explicit Assumptions
1. Action space is finite: $|\mathcal{A}| = m < \infty$.
2. Exploration parameter satisfies $\epsilon \in (0, 1]$.
3. $\pi$ is any valid $\epsilon$-soft policy, so $\sum_a \pi(a \mid s) = 1$ and $\pi(a \mid s) \ge \frac{\epsilon}{m}$.

##### Underlying Intuition
An $\epsilon$-soft policy reserves an $\epsilon$ probability budget for uniform random exploration and distributes the remaining $(1 - \epsilon)$ probability mass across actions. The optimal way to allocate that $(1 - \epsilon)$ surplus is to place $100\%$ of it on the single action that maximizes $Q^\pi(s, a)$. Any other allocation gives mass to sub-optimal actions, which cannot exceed placing all surplus on the highest-scoring action.

##### End-to-End Mathematical Derivation

**Step 1: Decomposition of Value under Current Policy $\pi$**
Recall the relationship between state values and action values:
$$V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) Q^\pi(s, a)$$
Because $\pi$ is $\epsilon$-soft, $\pi(a \mid s) \ge \frac{\epsilon}{m}$ for all $a$. We write:
$$\pi(a \mid s) = \frac{\epsilon}{m} + \Delta_\pi(a \mid s), \quad \text{where } \Delta_\pi(a \mid s) \ge 0$$
Notice the sum of surplus weights:
$$\sum_{a \in \mathcal{A}} \Delta_\pi(a \mid s) = \sum_{a \in \mathcal{A}} \left( \pi(a \mid s) - \frac{\epsilon}{m} \right) = 1 - m \left( \frac{\epsilon}{m} \right) = 1 - \epsilon$$
Substitute this into $V^\pi(s)$:
$$V^\pi(s) = \sum_{a \in \mathcal{A}} \left[ \frac{\epsilon}{m} + \Delta_\pi(a \mid s) \right] Q^\pi(s, a) = \frac{\epsilon}{m} \sum_{a \in \mathcal{A}} Q^\pi(s, a) + \sum_{a \in \mathcal{A}} \Delta_\pi(a \mid s) Q^\pi(s, a)$$

**Step 2: Upper Bounding the Surplus Term**
Let $a^* \in \arg\max_{a \in \mathcal{A}} Q^\pi(s, a)$, so $Q^\pi(s, a) \le Q^\pi(s, a^*)$ for all $a$.
Because $\Delta_\pi(a \mid s) \ge 0$:
$$\sum_{a \in \mathcal{A}} \Delta_\pi(a \mid s) Q^\pi(s, a) \le \sum_{a \in \mathcal{A}} \Delta_\pi(a \mid s) Q^\pi(s, a^*) = Q^\pi(s, a^*) \sum_{a \in \mathcal{A}} \Delta_\pi(a \mid s) = (1 - \epsilon) Q^\pi(s, a^*)$$
Therefore:
$$V^\pi(s) \le \frac{\epsilon}{m} \sum_{a \in \mathcal{A}} Q^\pi(s, a) + (1 - \epsilon) Q^\pi(s, a^*)$$

**Step 3: Evaluating the Expected Value under $\epsilon$-Greedy Policy $\pi'$**
Now compute the expected action-value under the proposed $\epsilon$-greedy policy $\pi'$:
$$\begin{aligned}
\sum_{a \in \mathcal{A}} \pi'(a \mid s) Q^\pi(s, a) &= \pi'(a^* \mid s) Q^\pi(s, a^*) + \sum_{a \ne a^*} \pi'(a \mid s) Q^\pi(s, a) \\
&= \left( 1 - \epsilon + \frac{\epsilon}{m} \right) Q^\pi(s, a^*) + \sum_{a \ne a^*} \frac{\epsilon}{m} Q^\pi(s, a) \\
&= (1 - \epsilon) Q^\pi(s, a^*) + \frac{\epsilon}{m} Q^\pi(s, a^*) + \sum_{a \ne a^*} \frac{\epsilon}{m} Q^\pi(s, a) \\
&= (1 - \epsilon) Q^\pi(s, a^*) + \frac{\epsilon}{m} \sum_{a \in \mathcal{A}} Q^\pi(s, a)
\end{aligned}$$
Comparing this exact expression to the upper bound established in Step 2:
$$\sum_{a \in \mathcal{A}} \pi'(a \mid s) Q^\pi(s, a) \ge V^\pi(s)$$

**Step 4: Monotonic Value Function Improvement**
By the Policy Improvement Theorem (Derivation 11.3.3):
Because $\mathbb{E}_{\pi'}[Q^\pi(s, \pi'(s))] \ge V^\pi(s)$ for all $s \in \mathcal{S}$, unrolling the recursive Bellman expectation under $\pi'$ to infinite horizon yields:
$$V^{\pi'}(s) \ge V^\pi(s), \quad \forall s \in \mathcal{S} \quad \blacksquare$$

#### Derivation 11.5.3: Bias-Variance Tradeoff: Ordinary vs. Weighted vs. Per-Decision Importance Sampling

##### Problem Statement & Goal
Let trajectories $\tau = (S_0, A_0, R_1, \dots, S_T)$ be sampled from behavior policy $b$ while evaluating target policy $\pi$.
Define the trajectory importance sampling ratio:
$$\rho_{0:T-1} \equiv \prod_{k=0}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}$$
We analyze three estimators of $V^\pi(S_0)$:
1. **Ordinary Importance Sampling (OIS):** $\hat{V}_{\text{OIS}} = \frac{1}{M} \sum_{m=1}^M \rho_m G^{(m)}$
2. **Weighted Importance Sampling (WIS):** $\hat{V}_{\text{WIS}} = \frac{\sum_{m=1}^M \rho_m G^{(m)}}{\sum_{m=1}^M \rho_m}$
3. **Per-Decision Importance Sampling (PDIS):** $\hat{V}_{\text{PDIS}} = \frac{1}{M} \sum_{m=1}^M \sum_{t=0}^{T_m-1} \rho_{0:t}^{(m)} \gamma^t R_{t+1}^{(m)}$
We prove:
1. OIS and PDIS are unbiased: $\mathbb{E}_b[\hat{V}_{\text{OIS}}] = \mathbb{E}_b[\hat{V}_{\text{PDIS}}] = V^\pi$.
2. $\operatorname{Var}(\hat{V}_{\text{PDIS}}) \le \operatorname{Var}(\hat{V}_{\text{OIS}})$, because future importance ratios $\rho_{t+1:T-1}$ are conditionally independent zero-mean noise when paired with past rewards $R_{t+1}$.
3. WIS has bounded variance for any sample size $M \ge 1$ at the cost of a finite-sample bias of order $\mathcal{O}(1/M)$.

##### Explicit Assumptions
1. Coverage: $b(a \mid s) > 0$ whenever $\pi(a \mid s) > 0$.
2. Episodic trajectories terminate in $T < \infty$ steps with bounded returns $|G| \le G_{\max} < \infty$.

##### Underlying Intuition
In standard trajectory-level OIS, the entire return $G_0 = R_1 + \gamma R_2 + \dots + \gamma^{T-1} R_T$ is multiplied by the full product of ratios $\rho_{0:T-1}$. But physically, an action taken at step $T-1$ can never retroactively influence reward $R_1$ collected at step 1! The extra factors $\frac{\pi(A_{T-1} \mid S_{T-1})}{b(A_{T-1} \mid S_{T-1})}$ have mean 1, so while they don't bias the expectation, they act as pure multiplicative noise multiplying $R_1$, exploding the variance exponentially. PDIS truncates the weight to only those actions preceding each reward.

##### End-to-End Mathematical Derivation

**Step 1: Proof of Unbiasedness of Ordinary Importance Sampling**
Let $\tau \sim b$. The expected value of the weighted return $\rho_{0:T-1} G_0$ under $b$ is:
$$\mathbb{E}_b \left[ \rho_{0:T-1} G_0 \right] = \sum_{\tau} \mathbb{P}(\tau \mid b) \left( \frac{\mathbb{P}(\tau \mid \pi)}{\mathbb{P}(\tau \mid b)} G(\tau) \right)$$
Assuming coverage ($\mathbb{P}(\tau \mid b) > 0$ whenever $\mathbb{P}(\tau \mid \pi) > 0$), $\mathbb{P}(\tau \mid b)$ cancels identically:
$$\mathbb{E}_b \left[ \rho_{0:T-1} G_0 \right] = \sum_{\tau} \mathbb{P}(\tau \mid \pi) G(\tau) = \mathbb{E}_\pi \left[ G_0 \right] = V^\pi(S_0)$$
Hence $\hat{V}_{\text{OIS}}$ is strictly unbiased.

**Step 2: Causality and Per-Decision Variance Reduction**
Decompose the return into individual discounted rewards:
$$\rho_{0:T-1} G_0 = \rho_{0:T-1} \sum_{t=0}^{T-1} \gamma^t R_{t+1} = \sum_{t=0}^{T-1} \rho_{0:T-1} \gamma^t R_{t+1}$$
Split the importance ratio into past and future components relative to time $t$:
$$\rho_{0:T-1} = \rho_{0:t} \cdot \rho_{t+1:T-1}, \quad \text{where } \rho_{0:t} = \prod_{k=0}^t \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}, \quad \rho_{t+1:T-1} = \prod_{k=t+1}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}$$
Consider the conditional expectation of the future ratio given the trajectory up to time $t+1$:
$$\mathbb{E}_b \left[ \rho_{t+1:T-1} \;\middle|\; S_0, A_0, \dots, S_t, A_t, R_{t+1} \right] = \mathbb{E}_b \left[ \prod_{k=t+1}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)} \;\middle|\; S_{t+1} \right]$$
Evaluating the one-step expectation at any step $k > t$:
$$\mathbb{E}_b \left[ \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)} \;\middle|\; S_k \right] = \sum_{a \in \mathcal{A}} b(a \mid S_k) \frac{\pi(a \mid S_k)}{b(a \mid S_k)} = \sum_{a \in \mathcal{A}} \pi(a \mid S_k) = 1$$
By the tower property of conditional expectation:
$$\mathbb{E}_b \left[ \rho_{t+1:T-1} \;\middle|\; \mathcal{H}_{t+1} \right] = 1$$
Therefore:
$$\mathbb{E}_b \left[ \rho_{0:T-1} \gamma^t R_{t+1} \right] = \mathbb{E}_b \left[ \rho_{0:t} \gamma^t R_{t+1} \cdot \mathbb{E}_b \left[ \rho_{t+1:T-1} \mid \mathcal{H}_{t+1} \right] \right] = \mathbb{E}_b \left[ \rho_{0:t} \gamma^t R_{t+1} \cdot 1 \right] = \mathbb{E}_b \left[ \rho_{0:t} \gamma^t R_{t+1} \right]$$
Define the Per-Decision Importance Sampling (PDIS) return:
$$G^{\text{PDIS}} \equiv \sum_{t=0}^{T-1} \rho_{0:t} \gamma^t R_{t+1}$$
This proves $\mathbb{E}_b[G^{\text{PDIS}}] = \mathbb{E}_b[\rho_{0:T-1} G_0] = V^\pi(S_0)$.

**Step 3: Variance Reduction Proof**
Write $\rho_{0:T-1} \gamma^t R_{t+1} = \rho_{0:t} \gamma^t R_{t+1} + \rho_{0:t} \gamma^t R_{t+1} (\rho_{t+1:T-1} - 1)$.
Since $\mathbb{E}_b[\rho_{t+1:T-1} - 1 \mid \mathcal{H}_{t+1}] = 0$, the two terms are orthogonal (uncorrelated):
$$\operatorname{Var}_b\left( \rho_{0:T-1} \gamma^t R_{t+1} \right) = \operatorname{Var}_b\left( \rho_{0:t} \gamma^t R_{t+1} \right) + \mathbb{E}_b\left[ \left( \rho_{0:t} \gamma^t R_{t+1} \right)^2 \operatorname{Var}_b(\rho_{t+1:T-1} \mid \mathcal{H}_{t+1}) \right]$$
Because the second term is strictly non-negative:
$$\operatorname{Var}_b\left( \rho_{0:t} \gamma^t R_{t+1} \right) \le \operatorname{Var}_b\left( \rho_{0:T-1} \gamma^t R_{t+1} \right)$$
Summing across all time steps establishes that PDIS strictly reduces variance:
$$\operatorname{Var}(\hat{V}_{\text{PDIS}}) \le \operatorname{Var}(\hat{V}_{\text{OIS}})$$

**Step 4: Bounded Variance of Weighted Importance Sampling**
For any sample of $M$ episodes, the Weighted IS estimator is a convex combination:
$$\hat{V}_{\text{WIS}} = \sum_{m=1}^M \left( \frac{\rho_m}{\sum_{j=1}^M \rho_j} \right) G^{(m)}$$
Let $w_m \equiv \frac{\rho_m}{\sum_j \rho_j}$. Then $w_m \ge 0$ and $\sum_{m=1}^M w_m = 1$.
Because $\hat{V}_{\text{WIS}}$ is a convex combination of returns, its value is strictly bounded by the range of the returns:
$$\min_m G^{(m)} \le \hat{V}_{\text{WIS}} \le \max_m G^{(m)}$$
Consequently, even if a single ratio $\rho_m \to \infty$, the estimate cannot explode:
$$\operatorname{Var}(\hat{V}_{\text{WIS}}) \le \left( \frac{R_{\max}}{1 - \gamma} \right)^2 < \infty$$
By the delta method, the bias of $\hat{V}_{\text{WIS}}$ decays as $\mathcal{O}(1/M)$ and vanishes asymptotically:
$$\lim_{M \to \infty} \mathbb{E}[\hat{V}_{\text{WIS}}] = V^\pi(S_0) \quad \blacksquare$$

## 3. Geometric & Physical Interpretation

### Trajectory Measure Warping
Consider the space of all possible trajectory paths $\Omega$:
1. The behavior policy $b$ spreads probability mass broadly across the trajectory simplex to ensure diverse exploration.
2. The target policy $\pi$ concentrates mass on a narrow, high-reward manifold.
3. The importance weight $\rho(\tau) = \frac{d\mathbb{P}_\pi}{d\mathbb{P}_b}(\tau)$ acts as the **Radon-Nikodym derivative** that mathematically warps the empirical measure induced by $b$ into the true target measure of $\pi$.

### 5.3 Episode Trajectories & Return Calculations

$$\tau_1 = \left( S_1, a_1, R_1 = 2.0, \quad S_2, a_1, R_2 = 4.0, \quad \text{Terminal} \right)$$

- Return from $S_2$: $G_1^{(1)} = R_2 = \mathbf{4.0000}$

**Importance Sampling Ratio for Episode 1 from $S_1$:**
$$\rho_1 = \left( \frac{\pi(a_1 \mid S_1)}{b(a_1 \mid S_1)} \right) \times \left( \frac{\pi(a_1 \mid S_2)}{b(a_1 \mid S_2)} \right) = \left( \frac{1.0}{0.5} \right) \times \left( \frac{1.0}{0.5} \right) = 2.0 \times 2.0 = \mathbf{4.0000}$$

#### Episode 2 ($\tau_2$):
$$\tau_2 = \left( S_1, a_1, R_1 = 1.0, \quad S_2, a_2, R_2 = 0.0, \quad \text{Terminal} \right)$$
- Return from $S_1$: $G_0^{(2)} = R_1 + R_2 = 1.0 + 0.0 = \mathbf{1.0000}$
- Return from $S_2$: $G_1^{(2)} = R_2 = \mathbf{0.0000}$

**Importance Sampling Ratio for Episode 2 from $S_1$:**
$$\rho_2 = \left( \frac{\pi(a_1 \mid S_1)}{b(a_1 \mid S_1)} \right) \times \left( \frac{\pi(a_2 \mid S_2)}{b(a_2 \mid S_2)} \right) = \left( \frac{1.0}{0.5} \right) \times \left( \frac{0.0}{0.5} \right) = 2.0 \times 0.0 = \mathbf{0.0000}$$
(Because action $a_2$ would **never** be taken by target policy $\pi$, this trajectory has probability 0 under $\pi$, so $\rho_2 = 0$!).

### 5.5 Step 2: Off-Policy Value Estimation for Target Policy $\pi$

#### 1. Ordinary Importance Sampling ($V_{\text{OIS}}$)
$$V_{\text{OIS}}(S_1) = \frac{1}{M} \sum_{m=1}^2 \rho_m G^{(m)} = \frac{\rho_1 G^{(1)} + \rho_2 G^{(2)}}{2}$$
$$= \frac{(4.0000 \times 6.0000) + (0.0000 \times 1.0000)}{2} = \frac{24.0000 + 0.0000}{2} = \frac{24.0000}{2} = \mathbf{12.0000}$$

#### 2. Weighted Importance Sampling ($V_{\text{WIS}}$)
$$V_{\text{WIS}}(S_1) = \frac{\sum_{m=1}^2 \rho_m G^{(m)}}{\sum_{m=1}^2 \rho_m} = \frac{\rho_1 G^{(1)} + \rho_2 G^{(2)}}{\rho_1 + \rho_2}$$
$$= \frac{(4.0000 \times 6.0000) + (0.0000 \times 1.0000)}{4.0000 + 0.0000} = \frac{24.0000}{4.0000} = \mathbf{6.0000}$$

**Profound Insight from Hand Calculation:**
- Target policy $\pi$ deterministically takes action sequence $(a_1, a_1)$.
- Episode 1 is the **only** trajectory that followed target policy $\pi$'s choices, yielding return $G = 6.0$.
- **Weighted IS** correctly normalized the weight and produced $V_{\text{WIS}} = \mathbf{6.0000}$ (the exact true value of that path!).
- **Ordinary IS** scaled by $1/M = 1/2$, artificially doubling the estimated return to $\mathbf{12.0000}$ due to weight explosion!

## 6. Solved Illustrations

### Illustration 1: Infinite Variance of Ordinary Importance Sampling
**Problem (Sutton & Barto Counterexample):**
Consider a 1-state MDP. State $S$ has two actions: `back` ($a_1$) and `end` ($a_2$).
- Action `back` returns to $S$ with reward $0$.
- Action `end` terminates with reward $+1$.
Target policy $\pi(\text{back} \mid S) = 1.0$. (Target policy loops forever, return is $0$).
Behavior policy $b(\text{back} \mid S) = 0.5, b(\text{end} \mid S) = 0.5$.
Prove that the second moment (and hence the variance) of the Ordinary Importance Sampling estimator is **infinite**.
**Solution:**
A trajectory consisting of $k$ `back` actions followed by `end` has return $G = 1$ (if undiscounted).
Probability under $b$: $\mathbb{P}_b = (0.5)^k \times 0.5 = (0.5)^{k+1}$.
Probability under $\pi$: For any `end` action, $\pi(\text{end}) = 0$. Thus, $\rho = 0$ for all terminating episodes!
If reward is given upon termination, consider an episode where termination yields $1$:
Importance ratio: $\rho = \frac{1.0^k \times 0}{0.5^{k+1}} = 0$.
Now consider target policy $\pi(\text{back}) = 1.0$ and reward on `end` with $\gamma < 1$:
The second moment of the estimator $X = \rho G$ is:
$$\mathbb{E}_b[X^2] = \sum_{k=0}^\infty \mathbb{P}_b(\tau_k) \cdot \left( \rho_k G_k \right)^2 = \sum_{k=0}^\infty (0.5)^{k+1} \left( \frac{1.0^k}{0.5^k} \times 1 \right)^2 = \sum_{k=0}^\infty \frac{1}{2^{k+1}} \left( 2^k \right)^2 = \sum_{k=0}^\infty \frac{4^k}{2^{k+1}} = \frac{1}{2} \sum_{k=0}^\infty 2^k = +\infty$$
The second moment diverges to $+\infty$!
Even after millions of samples, Ordinary Importance Sampling will never settle down, experiencing massive periodic explosive spikes. Weighted Importance Sampling completely eliminates this pathology! $\blacksquare$

### Illustration 2: First-Visit vs. Every-Visit Monte Carlo Prediction on Multi-Visit Cyclic Trajectories

**Problem:**
Consider a Markov process with states $\mathcal{S} = \{S_1, S_2, \text{Terminal}\}$ and undiscounted returns ($\gamma = 1.00$).
An agent follows a fixed policy and observes two complete trajectories:
- **Episode 1 ($\tau_1$):**
  $$\tau_1 = \left( S_1, R_1 = 2.0, \quad S_2, R_2 = 1.0, \quad S_1, R_3 = 4.0, \quad S_2, R_4 = -2.0, \quad S_1, R_5 = 5.0, \quad \text{Terminal} \right)$$
- **Episode 2 ($\tau_2$):**
  $$\tau_2 = \left( S_1, R_1 = 3.0, \quad \text{Terminal} \right)$$

1. Identify every visit to state $S_1$ and calculate the exact return from each occurrence.
2. Compute the First-Visit Monte Carlo estimate $\hat{V}_{\text{FV}}(S_1)$.
3. Compute the Every-Visit Monte Carlo estimate $\hat{V}_{\text{EV}}(S_1)$.
4. Analyze the sample correlation present in Every-Visit returns.

**Solution:**

**Step 1: Calculate Returns from Each Occurrence of $S_1$**
In Episode 1, state $S_1$ is visited three separate times ($t = 0, t = 2, t = 4$):
- **Visit 1 ($t = 0$):** First visit in Episode 1:
  $$G_0^{(1)} = R_1 + R_2 + R_3 + R_4 + R_5 = 2.0 + 1.0 + 4.0 + (-2.0) + 5.0 = \mathbf{10.0000}$$
- **Visit 2 ($t = 2$):** Second visit in Episode 1:
  $$G_2^{(1)} = R_3 + R_4 + R_5 = 4.0 + (-2.0) + 5.0 = \mathbf{7.0000}$$
- **Visit 3 ($t = 4$):** Third visit in Episode 1:
  $$G_4^{(1)} = R_5 = \mathbf{5.0000}$$

In Episode 2, state $S_1$ is visited once:
- **Visit 1 ($t = 0$):** First visit in Episode 2:
  $$G_0^{(2)} = R_1 = \mathbf{3.0000}$$

**Step 2: First-Visit Monte Carlo Calculation**
First-Visit MC extracts solely the first occurrence of $S_1$ from each episode:
- From Episode 1: $G_0^{(1)} = 10.0000$
- From Episode 2: $G_0^{(2)} = 3.0000$
Number of episodes visiting $S_1$: $N_{\text{FV}}(S_1) = 2$.
$$\hat{V}_{\text{FV}}(S_1) = \frac{G_0^{(1)} + G_0^{(2)}}{2} = \frac{10.0000 + 3.0000}{2} = \frac{13.0000}{2} = \mathbf{6.5000}$$

**Step 3: Every-Visit Monte Carlo Calculation**
Every-Visit MC averages over all four occurrences across both episodes:
Total visits: $N_{\text{EV}}(S_1) = 3 + 1 = 4$.
$$\hat{V}_{\text{EV}}(S_1) = \frac{G_0^{(1)} + G_2^{(1)} + G_4^{(1)} + G_0^{(2)}}{4} = \frac{10.0000 + 7.0000 + 5.0000 + 3.0000}{4} = \frac{25.0000}{4} = \mathbf{6.2500}$$

**Step 4: Correlation and Bias Analysis**
Notice that the three returns from Episode 1 share identical downstream rewards:
$$G_0^{(1)} = 2.0 + 1.0 + G_2^{(1)}, \quad G_2^{(1)} = 4.0 - 2.0 + G_4^{(1)}$$
Because $G_0^{(1)}, G_2^{(1)}, G_4^{(1)}$ are positively correlated, Every-Visit MC introduces finite-sample correlation into the average. However, it utilizes 4 data points instead of 2, reducing sample variance on small datasets while remaining asymptotically consistent ($\hat{V}_{\text{EV}} \to V^\pi$ as total episodes $M \to \infty$).

### Illustration 3: Incremental Weighted Importance Sampling Hand Trace with Running Weights

**Problem:**
An off-policy Monte Carlo agent evaluates a target state-action pair $(S_1, a_1)$.
Initial running estimates are:
$$Q_0 = 0.0000, \quad C_0 = 0.0000$$
The agent observes three successive episodes with returns $G_n$ and importance weights $W_n = \rho_n$:
- Episode 1: $G_1 = 10.0000, \quad W_1 = 2.0000$
- Episode 2: $G_2 = 4.0000, \quad W_2 = 0.5000$
- Episode 3: $G_3 = 0.0000, \quad W_3 = 1.5000$

1. Trace the step-by-step updates for running cumulative weight $C_n = C_{n-1} + W_n$ and value estimate $Q_n = Q_{n-1} + \frac{W_n}{C_n} (G_n - Q_{n-1})$ for $n = 1, 2, 3$.
2. Verify that the incremental value $Q_n$ matches the exact batch weighted ratio $\frac{\sum_{i=1}^n W_i G_i}{\sum_{i=1}^n W_i}$ after every episode.

**Solution:**

**Step 1: Episode $n = 1$**
- Cumulative Weight:
  $$C_1 = C_0 + W_1 = 0.0 + 2.0000 = \mathbf{2.0000}$$
- Value Update:
  $$Q_1 = Q_0 + \frac{W_1}{C_1} (G_1 - Q_0) = 0.0 + \frac{2.0}{2.0} (10.0 - 0.0) = \mathbf{10.0000}$$
- Batch Verification:
  $$Q_1^{\text{batch}} = \frac{W_1 G_1}{W_1} = \frac{2.0 \times 10.0}{2.0} = \mathbf{10.0000} \quad (\text{Exact Match})$$

**Step 2: Episode $n = 2$**
- Cumulative Weight:
  $$C_2 = C_1 + W_2 = 2.0000 + 0.5000 = \mathbf{2.5000}$$
- Value Update:
  $$Q_2 = Q_1 + \frac{W_2}{C_2} (G_2 - Q_1) = 10.0000 + \frac{0.50}{2.50} (4.0000 - 10.0000) = 10.0000 + 0.20(-6.0000) = 10.0000 - 1.2000 = \mathbf{8.8000}$$
- Batch Verification:
  $$Q_2^{\text{batch}} = \frac{W_1 G_1 + W_2 G_2}{W_1 + W_2} = \frac{(2.0 \times 10.0) + (0.5 \times 4.0)}{2.0 + 0.5} = \frac{20.0 + 2.0}{2.5} = \frac{22.0}{2.5} = \mathbf{8.8000} \quad (\text{Exact Match})$$

**Step 3: Episode $n = 3$**
- Cumulative Weight:
  $$C_3 = C_2 + W_3 = 2.5000 + 1.5000 = \mathbf{4.0000}$$
- Value Update:
  $$Q_3 = Q_2 + \frac{W_3}{C_3} (G_3 - Q_2) = 8.8000 + \frac{1.50}{4.00} (0.0000 - 8.8000) = 8.8000 + 0.3750(-8.8000) = 8.8000 - 3.3000 = \mathbf{5.5000}$$
- Batch Verification:
  $$Q_3^{\text{batch}} = \frac{W_1 G_1 + W_2 G_2 + W_3 G_3}{W_1 + W_2 + W_3} = \frac{22.0 + (1.5 \times 0.0)}{4.0} = \frac{22.0}{4.0} = \mathbf{5.5000} \quad (\text{Exact Match})$$

The incremental recurrence produces identical results to the full batch weighted average at every step, requiring only $\mathcal{O}(1)$ memory instead of storing trajectory histories!

### Illustration 4: Per-Decision Importance Sampling vs. Trajectory-Level Importance Sampling Variance Reduction Trace

**Problem:**
An agent generates a 3-step episodic trajectory under behavior policy $b$:
$$\tau = \left( S_0, A_0, R_1 = 2.0, \quad S_1, A_1, R_2 = 0.0, \quad S_2, A_2, R_3 = 10.0, \quad \text{Terminal} \right)$$
Discount factor: $\gamma = 1.00$.
The one-step policy importance ratios $\rho_t = \frac{\pi(A_t \mid S_t)}{b(A_t \mid S_t)}$ are:
$$\rho_0 = 2.0000, \quad \rho_1 = 0.5000, \quad \rho_2 = 3.0000$$

1. Compute the full trajectory importance sampling ratio $\rho_{0:2}$.
2. Compute the Ordinary Importance Sampling return estimate $G^{\text{OIS}}$.
3. Compute the Per-Decision Importance Sampling return estimate $G^{\text{PDIS}}$.
4. Demonstrate why $G^{\text{PDIS}}$ eliminates irrelevant downstream variance without introducing bias.

**Solution:**

**Step 1: Full Trajectory Importance Ratio**
$$\rho_{0:2} = \rho_0 \times \rho_1 \times \rho_2 = 2.0000 \times 0.5000 \times 3.0000 = 1.0000 \times 3.0000 = \mathbf{3.0000}$$

**Step 2: Ordinary Importance Sampling Return $G^{\text{OIS}}$**
Total episodic return:
$$G_0 = R_1 + R_2 + R_3 = 2.0 + 0.0 + 10.0 = \mathbf{12.0000}$$
The full trajectory-weighted estimator multiplies the total return by $\rho_{0:2}$:
$$G^{\text{OIS}} = \rho_{0:2} G_0 = 3.0000 \times 12.0000 = \mathbf{36.0000}$$

**Step 3: Per-Decision Importance Sampling Return $G^{\text{PDIS}}$**
By Derivation 11.5.3, the Per-Decision formula weights each reward $R_{t+1}$ solely by the causal historical ratios up to step $t$:
$$G^{\text{PDIS}} = \rho_{0:0} R_1 + \rho_{0:1} R_2 + \rho_{0:2} R_3$$
Compute each causal cumulative weight:
- For $R_1$: weight is $\rho_{0:0} = \rho_0 = \mathbf{2.0000}$
- For $R_2$: weight is $\rho_{0:1} = \rho_0 \times \rho_1 = 2.0 \times 0.5 = \mathbf{1.0000}$
- For $R_3$: weight is $\rho_{0:2} = \rho_0 \times \rho_1 \times \rho_2 = 2.0 \times 0.5 \times 3.0 = \mathbf{3.0000}$

Evaluate the PDIS return:
$$G^{\text{PDIS}} = (2.0000 \times 2.0) + (1.0000 \times 0.0) + (3.0000 \times 10.0) = 4.0000 + 0.0000 + 30.0000 = \mathbf{34.0000}$$

**Step 4: Variance Analysis and Causality**
Notice the fundamental difference between the two estimators:
- In $G^{\text{OIS}}$, immediate reward $R_1 = 2.0$ was multiplied by $\rho_{0:2} = 3.0$, yielding contribution $3.0 \times 2.0 = 6.0$.
  The extra factor $\rho_1 \rho_2 = 0.5 \times 3.0 = 1.5$ originated from actions $A_1$ and $A_2$ chosen **after** reward $R_1$ was already received!
- In $G^{\text{PDIS}}$, $R_1$ was multiplied strictly by $\rho_0 = 2.0$, yielding contribution $2.0 \times 2.0 = 4.0$.
Because $\mathbb{E}_b[\rho_1 \rho_2 \mid S_1] = 1$, the extra factor in $G^{\text{OIS}}$ does not change the expectation, but adds pure variance:
$$\operatorname{Var}\left( \rho_0 \rho_1 \rho_2 R_1 \right) > \operatorname{Var}\left( \rho_0 R_1 \right)$$
PDIS strictly purges all non-causal future noise, achieving massive variance reduction across extended episode horizons!

## 7. Deep Learning Connection & Application

### 1. AlphaGo & MCTS Monte Carlo Rollouts (Silver et al., Nature 2016)
In the original AlphaGo, the leaf evaluation of Monte Carlo Tree Search used a hybrid:
$$V(s_L) = (1 - \lambda) v_\theta(s_L) + \lambda G_L$$
where $G_L$ was the outcome of a **fast Monte Carlo rollout** to the end of the game using a lightweight policy. This pure Monte Carlo sample prevented the neural network $v_\theta$ from hallucinating blind spots!

### 2. REINFORCE as Monte Carlo Policy Optimization
The foundational Policy Gradient algorithm (Chapter 11.13) is an on-policy Monte Carlo method:
$$\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_{t=0}^T G_t \nabla_\theta \log \pi_\theta(A_t \mid S_t) \right]$$
It uses full episodic Monte Carlo returns $G_t$ to compute unbiased gradient estimates without an environment model.
