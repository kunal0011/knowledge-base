# C++: High-Performance Tricks & STL Idioms

**Target Audience:** Software engineers and competitive programmers looking to write blazing-fast, modern C++ code  
**Topic:** Fast I/O mechanics, GCC hardware builtins, `<bit>` library, C++17 structured bindings, and the `std::bitset` knapsack trick

---

## 1. Fast I/O: The Three Golden Commands

By default, C++ standard I/O is synchronized with C standard I/O (`stdio.h`), and `std::cin` is tied to `std::cout`. This introduces massive context-switching overhead on large datasets ($10^6$ inputs).

```cpp
int main() {
    std::ios_base::sync_with_stdio(false);
    std::cin.tie(nullptr);
    std::cout.tie(nullptr);
    
    // ... algorithm logic ...
    return 0;
}
```

### Why it Works:
1. **`sync_with_stdio(false)`:** Disables synchronization between C++ streams (`cin`/`cout`) and C streams (`scanf`/`printf`). Allows `std::cin` to maintain an internal $8\text{ KB}-16\text{ KB}$ buffer without flushing on every token.
2. **`cin.tie(nullptr)`:** Unties `cin` from `cout`. By default, any read from `cin` forces an immediate flush of `cout`'s buffer so prompts are displayed to terminal users. In batch execution (LeetCode), this causes millions of unnecessary flush syscalls.
3. **Avoid `std::endl`:** Always use `'\n'`. `std::endl` writes a newline character **and forces a physical buffer flush** (`std::flush`).

## 2. GCC Compiler Builtins & C++20 `<bit>`

GCC and Clang compile these built-in functions directly into single-cycle CPU hardware instructions:

```cpp
int x = 40; // binary: 00000000_00000000_00000000_00101000

// 1. Popcount (Count Set Bits): Maps to CPU POPCNT instruction
int count = __builtin_popcount(x);       // 2 (for 32-bit int)
int count_ll = __builtin_popcountll(1ULL << 40); // 1 (for 64-bit uint64_t)

// 2. Count Leading Zeros (Undefined if x == 0!): Maps to LZCNT
int lz = __builtin_clz(x);               // 26

// 3. Count Trailing Zeros (Undefined if x == 0!): Maps to TZCNT
int tz = __builtin_ctz(x);               // 3

// 4. Parity (1 if odd number of bits set, 0 if even):
int p = __builtin_parity(x);             // 0
```

### Modern C++20 `<bit>` Library (Standardized):
```cpp
#include <bit>

unsigned int n = 40;
int pop = std::popcount(n);               // 2
int clz = std::countl_zero(n);            // 26 (Safe when n == 0)
int ctz = std::countr_zero(n);            // 3  (Safe when n == 0)
bool is_pow2 = std::has_single_bit(n);    // false
int ceil_p2 = std::bit_ceil(n);           // 64 (Next power of 2)
```

## 3. Binary Search STL Idioms

In C++, binary search algorithms operate on sorted ranges via iterators:

```cpp
std::vector<int> v = {10, 20, 20, 20, 30, 40};

// 1. std::lower_bound: First element >= target
auto it1 = std::lower_bound(v.begin(), v.end(), 20);
int idx1 = it1 - v.begin(); // Index 1

// 2. std::upper_bound: First element strictly > target
auto it2 = std::upper_bound(v.begin(), v.end(), 20);
int idx2 = it2 - v.begin(); // Index 4

// 3. Count occurrences of target in O(log N) time:
int occurrences = std::upper_bound(v.begin(), v.end(), 20) - 
                  std::lower_bound(v.begin(), v.end(), 20); // 3

// 4. std::binary_search: Fast check if target exists
bool exists = std::binary_search(v.begin(), v.end(), 25); // false
```

## 5. `std::bitset`: The 64x Knapsack Speedup

`std::bitset<N>` represents a fixed-size sequence of $N$ bits. Bitwise operations on bitsets execute across 64-bit integer words simultaneously using native CPU ALU registers.

### Accelerating 0/1 Knapsack Subset-Sum by 64x:
Can a subset of elements sum to target $T$?
Standard DP: $\mathcal{O}(N \times T)$ time.
Bitset DP: **$\mathcal{O}\left(\frac{N \times T}{64}\right)$** time!

```cpp
#include <bitset>
#include <vector>

bool canPartition(std::vector<int>& nums, int target) {
    // dp[s] = 1 if sum 's' is reachable, 0 otherwise
    std::bitset<100001> dp;
    dp[0] = 1; // Base case: sum 0 is always reachable

    for (int num : nums) {
        dp |= (dp << num); // Shift reachable sums by num and bitwise OR
    }

    return dp[target];
}
```

## 6. Zero-Overhead Recursive Lambdas (Generic Lambdas)

In C++, recursion inside an inline lambda traditionally required wrapping with `std::function`, which incurs heap allocation and dynamic virtual dispatch overhead.

### The Fast C++14 `auto&& self` Idiom:
```cpp
// Zero-overhead recursive DFS lambda:
auto dfs = [&](auto&& self, int u, int parent) -> void {
    for (int v : adj[u]) {
        if (v != parent) {
            self(self, v, u); // Pass self recursively
        }
    }
};

dfs(dfs, 0, -1);
```
Because the compiler knows the exact lambda type statically, this generates **zero function pointer indirection** and can be aggressively inlined by the optimizer.

## 7. `std::iota`: Quick Sequence Filling

Populates a range with sequentially increasing values starting from a given initial value:

```cpp
#include <numeric>
#include <vector>

std::vector<int> parent(n);
// Initialize DSU parent array: parent[i] = i
std::iota(parent.begin(), parent.end(), 0);
```
